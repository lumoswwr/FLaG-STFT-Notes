## 实验详细论述 {#detail}

### 3. 第二步：观察训练后的 Gate 实际在做什么

#### 3.1 不同句子的 Gate 是否不同？

按照 FLaG 的设计，每个句子经过 FFT、latent attention 和 Gate MLP，会计算出自己的 Gate。为检验“每句话都需要自己那套 Gate”是否真的影响预测，我们固定一个已经训练好的模型，不重新训练，只在推理时换 Gate：

| 处理 | 具体含义 |
| --- | --- |
| 使用自身 Gate | 句子 A 使用根据 A 计算的缩放系数 |
| 使用训练集平均 Gate | 先用训练集句子算出平均缩放系数，以后所有句子共用 |
| 交换句子 Gate | 句子 A 使用同一批中其他句子计算的缩放系数 |

结果是，**四个模型/任务组合的官方 test 指标，三种处理方式都相同到小数点后六位**：

| 模型与任务 | 使用自身 Gate | 训练集平均 Gate | 交换其他句子的 Gate |
| --- | ---: | ---: | ---: |
| STSB：FLaG，Spearman | 0.843379 | 0.843379 | 0.843379 |
| STSB：B2，Spearman | 0.845488 | 0.845488 | 0.845488 |
| Sprint：FLaG，AP | 0.848503 | 0.848503 | 0.848503 |
| Sprint：B2，AP | 0.833946 | 0.833946 | 0.833946 |

最初记录中，Gate 与训练集平均 Gate 的差异仅打印到五位小数，因此显示为 $0.00000$。我们随后补做了高精度数值检查，确认**实际 Gate 不是严格不变，但不同句子之间的变化极小**。完整数据见下一节。

这一结果与推理时交换 Gate 后指标不变的观察一致。但需注意：相同到六位小数的是 **Spearman / AP 指标**，不能据此推断每一句的预测值或 Gate 张量都逐元素完全相等。

这个现象与网站原有的 P1/P2、Sprint S3 相衔接：**旧实验**已发现更换 Gate 的频谱来源几乎不影响输出；**本次新增实验**则直接交换不同句子的 Gate，进一步测试输入相关性。

#### 3.2 高精度复核：为什么 Sigmoid 前有变化，Gate 却几乎不变？

为了区分“Gate 网络没有响应不同句子”和“Gate 网络的输出虽然有变化，却被最后的 Sigmoid 压缩”这两种情况，我们分别统计：

- **Sigmoid 前的 logits**：Gate MLP 最后一层产生的数值，还没有经过 Sigmoid。
- **实际 Gate**：经过 Sigmoid 和缩放后，真正乘到频谱上的系数。

对**同一个 Gate 通道**，先测它在不同句子间的标准差，再对所有通道的标准差取平均。这叫**跨句子通道标准差**。它衡量不同输入是否让该通道的系数发生变化，不是不同通道彼此之间的差异。

**Validation，seed 0，高精度统计：**

| 任务与模型 | Sigmoid 前 logits 的平均跨句子标准差 | 实际 Gate 的平均跨句子标准差 | Gate 相对训练集平均 Gate 的平均绝对差 |
| --- | ---: | ---: | ---: |
| STSB FLaG | 0.292946 | $7.86\times10^{-8}$ | $6.20\times10^{-8}$ |
| STSB B2 | 0.070029 | $8.01\times10^{-10}$ | $6.53\times10^{-10}$ |
| Sprint FLaG | 0.439389 | 数值计算为 0（见下文） | $7.58\times10^{-14}$ |
| Sprint B2 | 0.227895 | $1.73\times10^{-10}$ | $1.37\times10^{-10}$ |

从数据可以看到：**四个模型的 Sigmoid 前输出都在随句子变化，但最后实际 Gate 的变化远小于这些中间数值的变化**。

进一步观察 Sigmoid：大量通道的输出已经非常接近两端。例如 Sprint B2 约 95.96% 的 Sigmoid 输出大于 0.95，约 4.04% 小于 0.05。Sigmoid 在接近 0 和 1 时曲线非常平坦，即使输入 logits 变化，输出也可能只改变极微小的数值。这叫 **Sigmoid 饱和**。原始 FLaG 使用 $g=1+\sigma(\ell)$；B2 使用 $g=2\sigma(\ell)$。

我们还直接测量了 Gate 与**训练集平均 Gate** 的逐元素差异，避免只依赖四舍五入的指标：

| 任务与模型 | 每个句子各通道的最大绝对差，再对句子取平均 | 元素差异大于 $10^{-5}$ 的比例 |
| --- | ---: | ---: |
| STSB FLaG | $1.67\times10^{-5}$ | 0.1603% |
| STSB B2 | $3.46\times10^{-7}$ | 0% |
| Sprint FLaG | $1.16\times10^{-10}$ | 0% |
| Sprint B2 | $2.85\times10^{-8}$ | 0% |

这里第二列**不是所有样本的全局最大值**，而是先计算每个句子的最大通道差异，再对这些最大值求平均。尤其在 STSB FLaG 中，仍能测到少数非零变化，所以不能写成“Gate 严格恒定”。

**数值精度说明：** Sprint FLaG 的“Gate 跨句子标准差”在输出中显示为 0，但直接逐元素比较仍发现非零的极小差异。这是因为当前程序通过 $E[g^2]-E[g]^2$ 计算方差；当 Gate 几乎不变时，两个接近的量相减可能发生浮点精度损失。因此，“标准差为 0”**不能解释为数学上完全相同**。

**本次更新后的结论：** Gate 网络在 Sigmoid 前对不同输入仍然有响应；高度饱和的 Sigmoid 与最后 Gate 几乎不变的现象一致，说明输入引起的变化在最终缩放系数上被强烈压缩。结合前一节的 Gate 互换实验，**当前训练好的模型在推理时几乎不依赖明显的逐句 Gate 差异**。但这并不能证明 latent attention 在训练阶段没有作用。

#### 3.3 那些 Gate 较小的通道，原本有什么特点？

这里需要把“通道”说清楚。

设一条句子的原始 DC 实部为：

$$
x=(x_1,x_2,\ldots,x_{768}).
$$

Gate 的总长度是 $1536=2\times768$，前 768 项对应频谱**实部**的通道缩放，后 768 项对应**虚部**。由于 DC 虚部为零，这里只看前 768 项。

假设某句子的 DC 向量为 $x=(10,1,1)$，B2 的实部 Gate 为 $g_R=(0.02,1.9,1.9)$。第一个位置 Gate 很小，我们把它的**通道编号**放进集合 $S$，即 $S=\{1\}$。$S$ 不是 token 的位置，也不是 FFT 的频率编号。

我们计算的是：Gate 较小的通道，在**使用 Gate 以前**占了多少 DC 的平方能量。

$$
\text{低 Gate 值通道的 DC 能量比例}
=
\frac{\sum_{i\in S}x_i^2}{\sum_{i=1}^{768}x_i^2}.
$$

例如 $x=(10,1,1)$ 中，通道 1 占 $100/(100+1+1)\approx98.0\%$ 的平方能量。只调整这一个通道，就可能明显改变向量方向。

本实验将 sigmoid 输出小于 $0.05$ 的实部通道记为低值通道。对原始 FLaG，这意味着实际 Gate 小于 $1.05$；对 B2，意味着实际 Gate 小于 $0.1$。

**Sprint official test（seed 0）：**

| 统计 | 原始 FLaG | B2 |
| --- | ---: | ---: |
| 低值实部通道占 768 个通道的比例 | 2.214% | 3.776% |
| 这些通道占原始 DC 平方能量的比例 | **93.720%** | **95.488%** |
| 原始 DC 与门控后 DC 的平均夹角 | 12.811° | 77.773° |

STSB test 的能量比例分别为 75.416% 和 80.208%。

**重要观察**：少量低 Gate 值通道恰好承载了原始 DC 的大量平方能量。原始 FLaG 将这些通道乘以约 1、其他许多通道乘以约 2，所以它是在**相对减弱**这些高能通道，而不是将其删除。B2 的相应 Gate 则可接近 0，抑制更强。

因此我们现在能够解释：**较少的通道被赋予不同的权重，也足以造成很大的 DC 方向变化。**

但不能仅凭这些统计认定高能通道是“无用信息”或“噪声”；也不能把坐标通道能量集中直接等同于某个已识别的语义主成分。

### 证据解释的范围

Gate 接近常数不等于严格恒定。通过 E[g²]−E[g]² 的数值方差为 0 也可能来自浮点消减；逐元素差异统计才提供了非零变化的证据。
