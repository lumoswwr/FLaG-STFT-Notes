  ### 实验十三（E13）：固定 Global FFT 长度能否改善模型？

  - **实验目的：** 既然 Global FLaG 对 padding 长度敏感，想知道从训练开始固定 FFT 长度是否能改善性能。
  - **实验思路：** 训练和推理时都将 FFT 长度固定为 128，其他模型结构保持不变。
  - **实验结果：** Test Spearman 为 0.841856，相比动态 FFT 的平均配对差为 +0.000728，但只有一个种子领先。
  - **实验结论：** 将 FFT 长度固定为 128 后，Spearman 与动态长度版本接近，没有带来改善。

## 实验详细论述

**实验口径：** STSB · test · 3 seeds · 重新训练。

### 1. 对照问题

如果 global FLaG 在训练时就使用固定 FFT 长度，能否改善结果？

### 2. 实验实施

global FLaG 在训练及推理时均设 `fixed_fft_length=128`；不引入 STFT，其他设置不变，**3 seeds（0–2）**。

### 3. 观测结果

test Spearman **0.841856 ± 0.001000**；相对同 seed 动态 FLaG 的配对差为 **+0.000728 ± 0.003079**，仅 **1/3 正向**。

### 4. 结果解读

固定 FFT 长度没有带来稳定的性能改善。

### 解释范围

平均配对差为正，但 3 个种子中只有 1 个正向，不能表述为稳定提升。
