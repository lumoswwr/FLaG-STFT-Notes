### 实验一（E1）：在 FFT 前增加 Hann 窗，能否改善模型性能？

- **实验目的：** 尝试减小序列两端带来的频谱边界影响，看看能否提高 STSB 的句子相似度预测能力。
- **实验思路：** 使用  FLaG，在 FFT 前对有效 token 特征乘上 Hann 窗函数，再用三个随机种子重新训练。
- **实验结果：** Test Spearman 从 FLaG 的 0.841128 降至 0.837019。
- **实验结论：** 全局 Hann 加窗使 Spearman 下降 0.004109，后续不采用这一加窗方案。

## 实验详细论述

**实验口径：** STSB · test Spearman · 3 seeds（0–2）· 重新训练。

### 1. 对照问题

global FFT 前加 Hann，能否减轻边界影响并改善性能？

### 2. 实验实施

按**每句话自身有效 token 长度**（包括特殊 token）生成 symmetric Hann，乘到 RoBERTa hidden 上，再执行原 global FFT；padding 仍为零。有效长度 ≤2 时使用全 1 窗口。其他设置与 FLaG 一致，**3 seeds**。

### 3. 观测结果

Spearman `0.837019 ± 0.002763`，比同 seed FLaG 平均 **−0.004109**。

### 4. 结果解读

未改善性能，但不能据此排除频谱泄漏，因为加窗同时减弱了边界 token 的输入。

### 解释范围

此对照同时改变了边界 token 的输入幅度，不能把指标下降单独解释为频谱泄漏的改变。
