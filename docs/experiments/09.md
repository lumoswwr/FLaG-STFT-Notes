  ### 实验九（E9）：只增加 Padding，为什么预测会变化？

  - **实验目的：** 检查模型是否会受到无效 padding 位置的影响。
  - **实验思路：** 固定 RoBERTa 已计算好的有效 token 特征，只在后面增加零 padding，分别比较 FLaG 和 E3(STFT) 的预测结果。
  - **实验结果：** 当补零长度达到 128 时，Global FLaG 的平均 cosine 预测变化约为 0.006003，最大为 0.035915；E3 几乎没有变化。
  - **实验结论：** 仅在有效 token 后增加零 Padding，就会改变 FLaG 的输出，E3 对这项操作不敏感。
