  ### 实验十六（P1）：Padding 的影响到底来自 Gate，还是频谱重建？

  - **实验目的：** 分清 Padding 导致预测变化的真正来源。
  - **实验思路：** 分别控制“生成 Gate 时采用的 FFT 长度”和“应用 Gate、逆 FFT 时采用的长度”，只改变其中一个。 补充实验中，再把实部与虚部 Gate 设为相同，去掉循环反射项。
  - **实验结果：** STSB validation 上，只改变 Gate 生成长度，平均 cosine 预测变化约 \(4.8\times10^{-7}\)；只改变逆变换长度，变化约 0.005520。 去掉循环反射后的输出与固定长度 128 的输出平均 cosine 差约为 0.000295。
  - **实验结论：** Padding 引起的预测差异主要来自应用 Gate 后的逆变换长度，而不是 Gate 的生成长度。取消循环反射后，也得到与固定重建长度相近的预测。

## 实验详细论述

**实验口径：** STSB · validation · 3 seeds · 固定 checkpoint 的门控/重建反事实。

### 1. 对照问题

padding 导致的预测变化主要来自 gate 变化，还是重建长度变化？

### 2. 实验实施

使用原始动态 FLaG **3 个 checkpoint**，分别控制生成 gate 的 FFT 长度 `Ng` 和应用 gate、逆 FFT 的长度 `Nr`。`T` 是正常 batch padding 长度。

| 配置 | Ng | Nr |
| --- | ---: | ---: |
| TT（原始） | T | T |
| 128T | 128 | T |
| T128 | T | 128 |
| 128128 | 128 | 128 |

### 3. 观测结果

STSB validation，**3-seed 相对 TT 的平均绝对 cosine 漂移**：

| 配置 | mean ± std |
| --- | ---: |
| TT | 0 |
| 128T（只换 gate 来源） | \((4.80\pm2.84)\times10^{-7}\) |
| T128（只换重建长度） | **0.005520 ± 0.000805** |
| 128128 | **0.005520 ± 0.000805** |

### 4. 结果解读

只改变 gate 输入频谱的长度几乎没有影响，当前 padding 敏感性主要来自**重建长度**。

### 对称门控的补充对照

### 1. 对照问题

如果强制实、虚 gate 相同，能否重现固定重建长度的预测变化？

### 2. 实验实施

对同一 checkpoint 令两个实际乘数都等于 `(a+b)/2`，使反射项系数为零，记为 **SYM**。比较 SYM、TT、T128。

### 3. 观测结果

STSB validation，3-seed 平均绝对 cosine 差：

| 对比 | mean ± std |
| --- | ---: |
| SYM 与 TT | 0.005576 ± 0.000761 |
| T128 与 TT | 0.005520 ± 0.000805 |
| SYM 与 T128 | **0.000295 ± 0.000003** |

### 4. 结果解读

SYM 和 T128 的预测变化高度接近，支持**循环反射是当前 padding 漂移的主要来源**。固定到 128 不等于每个有效 token 的反射项都为零：位置 0 始终自反。

### 解释范围

`SYM` 与 `T128` 的数值接近是已测模型下的预测证据，不表示固定 128 的循环反射项恒为零。
