  ### 实验十一（E11/E12）：STFT 的窗口重叠探究

  - **实验目的：** 判断相邻窗口的重叠是否真的能够提高模型性能。
  - **实验思路：** 比较窗口长度为 8 和 16，以及半窗口重叠和完全不重叠的四种组合。
  - **实验结果：** 长度 8 时，重叠版本 E3 略好；长度 16 时，不重叠版本 E12 更好。E12 的三种子 Test Spearman 为 0.843419。
  - **实验结论：** 窗口重叠并非获得较好 STSB 结果的必要条件。在长度 16 的设置中，无重叠 E12 更好，因此后续采用 E12。

## 实验详细论述

**实验口径：** STSB · test · 3 seeds · 重新训练四种窗口配置。

### 1. 对照问题

STFT 是否一定需要窗口重叠？

### 2. 实验实施

比较 win8/win16 与半窗重叠/无重叠，共四种 rect、`center=False` 的 STFT 配置。沿用 E2/E3，并补充重新训练 E11/E12，**每组 3 seeds（0–2）**，其他参数一致。

### 3. 观测结果

**3-seed test Spearman（mean ± std）**：

| 窗长 | 半窗口重叠 | 无重叠 |
| ---: | ---: | ---: |
| 8 | **E3**：hop4，0.843000 ± 0.001047 | **E11**：hop8，0.842166 ± 0.001423 |
| 16 | **E2**：hop8，0.842204 ± 0.001824 | **E12**：hop16，0.843419 ± 0.000531 |

### 4. 结果解读

重叠没有一致优势。后续固定使用结构简单的 **E12：rect、win16/hop16、center=False**。

### 解释范围

窗口大小与重叠是两个不同因素，结论只限于已测四种组合，且本实验各配置均使用 3 seeds。
