### 实验三（E3）：把窗口缩短，是否更适合短句？

- **实验目的：** 检查更短的局部窗口是否适合 STSB 中长度有限的句子。
- **实验思路：** 将窗口长度改为 8，步长改为 4，其他设置保持一致。
- **实验结果：** Test Spearman 达到 0.843000，比原始 FLaG 高 0.001873，三seed全正向。
- **实验结论：** 8/4 窗口在这组 STSB 实验中取得较高 Spearman，后续先以 E3 为局部模型进行机制分析。

## 实验详细论述

**实验口径：** STSB · test Spearman · 3 seeds · 重新训练。

### 1. 对照问题

部分短句在 win16 下只有一个有效帧，缩短窗口后效果如何？

### 2. 实验实施

延续 E2 的做法，改为 `win=8,hop=4`，其余不变，**3 seeds**。

Spearman `0.843000 ± 0.001047`；比 FLaG 平均 **+0.001873**（3/3 正向），比 E2 平均 **+0.000796**。

早期观察到小幅改善，因此选择 E3 进行 E6–E8 机制分析；3 seeds 不能证明稳定优势。
