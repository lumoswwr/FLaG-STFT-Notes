# Gate 与 Projection 的逐阶段作用

分离 FLaG 向量变化的来源，分析已训练 Gate 的输入依赖、低 Gate 通道能量以及关闭门控/投影时的预测变化。

## 实验总结

<a id="summary-32"></a>

  ### 实验三十二：FLaG 在哪一步改变了 Mean 向量？

  - **实验目的：** 找出 FLaG 为什么不能自动保持 Mean 的表示，以及具体是哪一部分改变了句向量方向。
  - **实验思路：** 将 FLaG 拆成 FFT、Gate、逆变换、Mean pooling 和 Projection 几个阶段。继承FLaG-A1 FLaG-zero想法，额外设计 B2，让模型初始时严格等于直接 Mean，再观察训练后的变化。
  - **实验结果：** B2 在第一个 epoch 后，Gate 使 STSB 和 Sprint 的 DC 平均转角分别达到约 64.7° 和 77.9°。最后的 Projection 还会进一步改变方向。
  - **实验结论：** FLaG 的 DC 与直接 Mean 原本同方向；。本次逐阶段测量表明，主要是 Gate 缩放和最终 Projection 改变了向量方向。

[查看本实验详细论述](#detail-32)

<a id="summary-33"></a>

  ### 实验三十三：Gate 是否真的会根据不同句子产生不同权重？

  - **实验目的：** FLaG 通过 FFT 和 latent attention 为每句话生成 Gate，想知道这种针对不同输入的调整是否真的明显存在。
  - **实验思路：** 固定训练好的模型，把当前句子的 Gate 替换成训练集平均 Gate，或者其他句子的 Gate。随后进一步测量 Sigmoid 前后数值在不同句子之间的变化。
  - **实验结果：** 更换 Gate 后，STSB 和 Sprint 的指标在六位小数精度下保持不变。高精度检查发现，Sprint FLaG 的 Sigmoid 前输出仍存在明显变化，平均跨句子标准差为 0.439389，但最终 Gate 与训练集平均 Gate 的平均绝对差仅约 \(7.58\times10^{-14}\)。
  - **实验结论：** Gate 网络对不同句子的 Sigmoid 前输出有明显变化，但最终 Gate 几乎一致。高度饱和的 Sigmoid 大幅压缩了输入带来的差异。

[查看本实验详细论述](#detail-33)

<a id="summary-34"></a>

  ### 实验三十四：Gate 主要在调整哪些特征通道？

  - **实验目的：** 解释为什么只有少量通道的 Gate 较低，却能够明显改变 DC 向量的方向。
  - **实验思路：** 找出 Gate 数值较低的实部通道，再计算这些位置在原始 DC 中占据多少平方能量。
  - **实验结果：** Sprint 中，原始 FLaG 约 2.21% 的低 Gate 值实部通道，承载了原始 DC 约 93.72% 的平方能量。B2 中相应比例为 3.78% 和 95.49%。
  - **实验结论：** 少量低 Gate 值通道承载了大部分原始 DC 平方能量，Gate 通过改变这些通道的相对权重影响向量方向。

[查看本实验详细论述](#detail-34)

<a id="summary-35"></a>

  ### 实验三十五：训练好的 FLaG 究竟依赖 Gate 的哪一部分？

  - **实验目的：** 判断频谱中 DC、其他频率的 Gate，以及最终 Projection，分别会怎样影响预测。
  - **实验思路：** 固定训练好的模型，在推理时依次关闭 DC Gate、非 DC Gate、全部 Gate，以及绕过 Projection，比较性能变化。
  - **实验结果：** Sprint B2 的 Test AP 为 0.833946；关闭 DC Gate 后下降至 0.678850；绕过 Projection 后下降至 0.494782。而只关闭非 DC Gate，AP 基本不变。
  - **实验结论：** 当前已训练 B2 的 Sprint 预测对 DC Gate 和输出 Projection 较敏感，而关闭非 DC Gate 基本不改变 AP。

## 实验详细论述

<a id="detail-32"></a>

### 实验三十二：FLaG 在哪一步改变了 Mean 向量？

**实验设置与评价：** STSB / Sprint · 初始与训练后 checkpoint · 阶段性向量夹角。

#### DC 与 Mean 究竟是什么关系？

rFFT 是沿 token 序列这个维度进行的。输出第一个频率位置称为 **DC（零频率分量）**。

对于 FFT 前已将 padding 位置置零的输入，有：

$$
X_0=\sum_{t\in\mathrm{valid}}h_t=Lm.
$$

所以 DC 的**实部**就是有效 token 特征的总和，与 Mean 向量只差一个正的倍数。DC 的虚部理论上为零。

为了找出方向在哪里改变，我们在同一句话上记录原始 Mean、原始 DC、经过 Gate 的 DC、iFFT 后的 masked Mean，以及最终线性层的输出，分别计算向量夹角。

这里的夹角是“同一句话在两个步骤中的表示方向差了多少”，**不是两句话之间的相似度**。

#### 为什么还要研究 Gate 和线性层的初始化？

仅观察训练完成的 FLaG，难以分清方向变化来自起点还是训练过程。因此比较了以下模型：

| 实验代号 | Gate 的缩放公式 | 输出线性层如何初始化 | 初始化是否严格等于 Mean |
| --- | --- | --- | --- |
| FLaG（原始参数化） | $g=1+\sigma(\ell)$ | 随机矩阵 | 否 |
| A1 | $g=1+\sigma(\ell)$ | 单位矩阵 | 否 |
| B1 | $g=2\sigma(\ell)$ | 单位矩阵 | 否 |
| B2 | $g=2\sigma(\ell)$，且 Gate 最后一层初始化为零 | 单位矩阵 | **是** |

$\sigma$ 表示 sigmoid 函数，$\ell$ 是 Gate 的线性层输出。



#### 实际测到哪些位置转了角度？

B2、seed 0、完成第一个 epoch 后：

| 同一句话的两个阶段 | STSB 平均角度 | Sprint 平均角度 |
| --- | ---: | ---: |
| 直接 Mean vs. 原始 DC | 约 0° | 约 0° |
| 原始 DC vs. Gate 处理后的 DC | **64.715°** | **77.867°** |
| 直接 Mean vs. iFFT 后的 masked Mean | 64.523° | 77.655° |
| 输出线性层的输入 vs. 输出 | 34.657° | 83.668° |

**我们得到的第一个解释**：FFT 自身保留 DC / Mean 的方向，重要的方向变化主要发生在 **Gate 缩放**和**最后的可学习线性层**。

但这并不是说“大角度导致性能下降”。如果所有句向量被一个共同正交变换旋转，每个句子相对于原来的方向可能变化很大，句子之间的余弦相似度却可以保持不变。

还有一个数学约束：原始 FLaG 的 Gate 位于 $(1,2)$，对 DC 做逐通道正缩放所能造成的最大角度约为 $19.47^\circ$；B2 位于 $(0,2)$，允许部分通道接近零，角度就能接近 $90^\circ$。因此，B2 比原始 FLaG 转得远，部分原因是两种 Gate **允许的缩放范围不同**，不能直接判断模型优劣。


B2 与原始 FLaG 的 Gate 缩放范围不同，角度较大不能直接被解释为模型更差。

### 实验三十三：Gate 是否真的会根据不同句子产生不同权重？

**实验设置与评价：** STSB / Sprint · 固定模型的 Gate 互换与数值测量。

Sprint FLaG 的 Sigmoid 前输出平均跨句标准差为 0.439389；最终 Gate 与训练集平均 Gate 的平均绝对差约为 7.58×10⁻¹⁴。数值精度限制见原记录。

#### 不同句子的 Gate 是否不同？

按照 FLaG 的设计，每个句子经过 FFT、latent attention 和 Gate MLP，会计算出自己的 Gate。为检验“每句话都需要自己那套 Gate”是否真的影响预测，我们固定一个已经训练好的模型，不重新训练，只在推理时换 Gate：

| 处理 | 具体含义 |
| --- | --- |
| 使用自身 Gate | 句子 A 使用根据 A 计算的缩放系数 |
| 使用训练集平均 Gate | 先用训练集句子算出平均缩放系数，以后所有句子共用 |
| 交换句子 Gate | 句子 A 使用同一批中其他句子计算的缩放系数 |

结果是，**四个模型/任务组合的官方 test 指标，三种处理方式都相同到小数点后六位**：

| 模型与任务 | 使用自身 Gate | 训练集平均 Gate | 交换其他句子的 Gate |
| --- | ---: | ---: | ---: |
| STSB：FLaG，Spearman | 0.843379 | 0.843379 | 0.843379 |
| STSB：B2，Spearman | 0.845488 | 0.845488 | 0.845488 |
| Sprint：FLaG，AP | 0.848503 | 0.848503 | 0.848503 |
| Sprint：B2，AP | 0.833946 | 0.833946 | 0.833946 |

最初记录中，Gate 与训练集平均 Gate 的差异仅打印到五位小数，因此显示为 $0.00000$。我们随后补做了高精度数值检查，确认**实际 Gate 不是严格不变，但不同句子之间的变化极小**。完整数据见下一节。

这一结果与推理时交换 Gate 后指标不变的观察一致。但需注意：相同到六位小数的是 **Spearman / AP 指标**，不能据此推断每一句的预测值或 Gate 张量都逐元素完全相等。

这个现象与网站原有的 P1/P2、Sprint S3 相衔接：**旧实验**已发现更换 Gate 的频谱来源几乎不影响输出；**本次新增实验**则直接交换不同句子的 Gate，进一步测试输入相关性。

#### 高精度复核：为什么 Sigmoid 前有变化，Gate 却几乎不变？

为了区分“Gate 网络没有响应不同句子”和“Gate 网络的输出虽然有变化，却被最后的 Sigmoid 压缩”这两种情况，我们分别统计：

- **Sigmoid 前的 logits**：Gate MLP 最后一层产生的数值，还没有经过 Sigmoid。
- **实际 Gate**：经过 Sigmoid 和缩放后，真正乘到频谱上的系数。

对**同一个 Gate 通道**，先测它在不同句子间的标准差，再对所有通道的标准差取平均。这叫**跨句子通道标准差**。它衡量不同输入是否让该通道的系数发生变化，不是不同通道彼此之间的差异。

**Validation，seed 0，高精度统计：**

| 任务与模型 | Sigmoid 前 logits 的平均跨句子标准差 | 实际 Gate 的平均跨句子标准差 | Gate 相对训练集平均 Gate 的平均绝对差 |
| --- | ---: | ---: | ---: |
| STSB FLaG | 0.292946 | $7.86\times10^{-8}$ | $6.20\times10^{-8}$ |
| STSB B2 | 0.070029 | $8.01\times10^{-10}$ | $6.53\times10^{-10}$ |
| Sprint FLaG | 0.439389 | 数值计算为 0（见下文） | $7.58\times10^{-14}$ |
| Sprint B2 | 0.227895 | $1.73\times10^{-10}$ | $1.37\times10^{-10}$ |

从数据可以看到：**四个模型的 Sigmoid 前输出都在随句子变化，但最后实际 Gate 的变化远小于这些中间数值的变化**。

进一步观察 Sigmoid：大量通道的输出已经非常接近两端。例如 Sprint B2 约 95.96% 的 Sigmoid 输出大于 0.95，约 4.04% 小于 0.05。Sigmoid 在接近 0 和 1 时曲线非常平坦，即使输入 logits 变化，输出也可能只改变极微小的数值。这叫 **Sigmoid 饱和**。原始 FLaG 使用 $g=1+\sigma(\ell)$；B2 使用 $g=2\sigma(\ell)$。

我们还直接测量了 Gate 与**训练集平均 Gate** 的逐元素差异，避免只依赖四舍五入的指标：

| 任务与模型 | 每个句子各通道的最大绝对差，再对句子取平均 | 元素差异大于 $10^{-5}$ 的比例 |
| --- | ---: | ---: |
| STSB FLaG | $1.67\times10^{-5}$ | 0.1603% |
| STSB B2 | $3.46\times10^{-7}$ | 0% |
| Sprint FLaG | $1.16\times10^{-10}$ | 0% |
| Sprint B2 | $2.85\times10^{-8}$ | 0% |

这里第二列**不是所有样本的全局最大值**，而是先计算每个句子的最大通道差异，再对这些最大值求平均。尤其在 STSB FLaG 中，仍能测到少数非零变化，所以不能写成“Gate 严格恒定”。

**数值精度说明：** Sprint FLaG 的“Gate 跨句子标准差”在输出中显示为 0，但直接逐元素比较仍发现非零的极小差异。这是因为当前程序通过 $E[g^2]-E[g]^2$ 计算方差；当 Gate 几乎不变时，两个接近的量相减可能发生浮点精度损失。因此，“标准差为 0”**不能解释为数学上完全相同**。

**本次更新后的结论：** Gate 网络在 Sigmoid 前对不同输入仍然有响应；高度饱和的 Sigmoid 与最后 Gate 几乎不变的现象一致，说明输入引起的变化在最终缩放系数上被强烈压缩。结合前一节的 Gate 互换实验，**当前训练好的模型在推理时几乎不依赖明显的逐句 Gate 差异**。但这并不能证明 latent attention 在训练阶段没有作用。


Sigmoid 前 logits 存在跨句变化；实际 Gate 的小差异不应表述为数学上的完全静态。

### 实验三十四：Gate 主要在调整哪些特征通道？

**实验设置与评价：** Sprint · 固定模型 · 实部通道的 DC 平方能量。

Sprint 中原 FLaG：低 Gate 的实部通道约占 2.21%，承载门控前 DC 平方能量的 93.72%；B2 分别约为 3.78% 和 95.49%。

#### 那些 Gate 较小的通道，原本有什么特点？

这里需要把“通道”说清楚。

设一条句子的原始 DC 实部为：

$$
x=(x_1,x_2,\ldots,x_{768}).
$$

Gate 的总长度是 $1536=2\times768$，前 768 项对应频谱**实部**的通道缩放，后 768 项对应**虚部**。由于 DC 虚部为零，这里只看前 768 项。

假设某句子的 DC 向量为 $x=(10,1,1)$，B2 的实部 Gate 为 $g_R=(0.02,1.9,1.9)$。第一个位置 Gate 很小，我们把它的**通道编号**放进集合 $S$，即 $S=\{1\}$。$S$ 不是 token 的位置，也不是 FFT 的频率编号。

我们计算的是：Gate 较小的通道，在**使用 Gate 以前**占了多少 DC 的平方能量。

$$
\text{低 Gate 值通道的 DC 能量比例}
=
\frac{\sum_{i\in S}x_i^2}{\sum_{i=1}^{768}x_i^2}.
$$

例如 $x=(10,1,1)$ 中，通道 1 占 $100/(100+1+1)\approx98.0\%$ 的平方能量。只调整这一个通道，就可能明显改变向量方向。

本实验将 sigmoid 输出小于 $0.05$ 的实部通道记为低值通道。对原始 FLaG，这意味着实际 Gate 小于 $1.05$；对 B2，意味着实际 Gate 小于 $0.1$。

**Sprint official test（seed 0）：**

| 统计 | 原始 FLaG | B2 |
| --- | ---: | ---: |
| 低值实部通道占 768 个通道的比例 | 2.214% | 3.776% |
| 这些通道占原始 DC 平方能量的比例 | **93.720%** | **95.488%** |
| 原始 DC 与门控后 DC 的平均夹角 | 12.811° | 77.773° |

STSB test 的能量比例分别为 75.416% 和 80.208%。

**重要观察**：少量低 Gate 值通道恰好承载了原始 DC 的大量平方能量。原始 FLaG 将这些通道乘以约 1、其他许多通道乘以约 2，所以它是在**相对减弱**这些高能通道，而不是将其删除。B2 的相应 Gate 则可接近 0，抑制更强。

因此我们现在能够解释：**较少的通道被赋予不同的权重，也足以造成很大的 DC 方向变化。**

但不能仅凭这些统计认定高能通道是“无用信息”或“噪声”；也不能把坐标通道能量集中直接等同于某个已识别的语义主成分。


这里的“低 Gate 通道”是实部**特征通道**而非频率位置或 token 位置；统计的是门控前 DC 能量。

### 实验三十五：训练好的 FLaG 究竟依赖 Gate 的哪一部分？

**实验设置与评价：** Sprint · seed 0 · 固定 checkpoint 的推理消融。

Sprint B2 Test AP：原值 0.833946；关闭 DC Gate 后为 0.678850；关闭非 DC Gate 后为 0.835823；绕过 Projection 后为 0.494782。

前面说明了 Gate 怎么改变向量。接着我们想知道：**如果临时关闭某部分 Gate，训练好的 FLaG 还能正常预测吗？**

我们固定原 checkpoint，不再训练，分别把 DC 的 Gate 改为 1、把非 DC 的 Gate 改为 1、全部改为 1，或者直接跳过输出线性层。

Sprint official test（seed 0）：

| 修改方式 | 原始 FLaG AP | B2 AP |
| --- | ---: | ---: |
| 什么都不改 | **0.848503** | **0.833946** |
| 仅取消 DC Gate 的缩放 | 0.838674 | 0.678850 |
| 仅取消非 DC 频率的 Gate 缩放 | 0.849550 | 0.835823 |
| 取消全部 Gate 缩放 | 0.840069 | 0.784842 |
| 保留 Gate、跳过最后的可学习线性层 | 0.464409 | 0.494782 |

这张表说明：

- **B2 的已训练参数高度依赖 DC Gate**：取消 DC 缩放，AP 从 0.833946 降为 0.678850。
- **在当前 Sprint 设置下，单独取消非 DC 缩放几乎没有损失**，但不能因此说所有非 DC 信息在所有任务中均无意义；STSB B2 的对应修改就出现了性能下降。
- **已训练的模型非常依赖最后的可学习线性层**。不经过它，Sprint AP 大幅降低。

这里尤其要区分两件事：训练完成后把 Projection 删除，模型当然可能崩，因为前面各层已与它共同适应；这并不表示“如果从一开始就不用复杂 Gate，模型就学不到好结果”。

因此，真正有必要做的是：**从一开始就训练一个不含复杂频域模块的简单模型**，而不是继续在现有 checkpoint 中删除组件。


推理时临时关闭模块，测的是**训练完成后的依赖**，不等价于从头训练时模块是否必需。
