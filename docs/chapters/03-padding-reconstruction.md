# Padding 敏感性与 Global/Local 重建机制

从补零导致的预测漂移开始，分别检查推理策略、固定 FFT 长度、循环反射的数学性质以及 Gate 来源与重建路径的独立作用。

## 实验总结

<a id="summary-09"></a>

  ### 实验九（E9）：只增加 Padding，为什么预测会变化？

  - **实验目的：** 检查模型是否会受到无效 padding 位置的影响。
  - **实验思路：** 固定 RoBERTa 已计算好的有效 token 特征，只在后面增加零 padding，分别比较 FLaG 和 E3(STFT) 的预测结果。
  - **实验结果：** 当补零长度达到 128 时，Global FLaG 的平均 cosine 预测变化约为 0.006003，最大为 0.035915；E3 几乎没有变化。
  - **实验结论：** 仅在有效 token 后增加零 Padding，就会改变 FLaG 的输出，E3 对这项操作不敏感。

<a id="summary-10"></a>

  ### 实验十（E10）：Padding 的变化会影响整个测试集的预测性能吗？

  - **实验目的：** 验证 E9 中观察到的预测变化，是否进一步影响 STSB 的整体 Spearman。
  - **实验思路：** 使用动态 padding、句对统一长度、每句精确长度以及统一长度 128 四种方式进行推理，不重新训练模型。
  - **实验结果：** FLaG 的平均 Test Spearman 在 0.841022 至 0.841458 之间变化，E3 基本保持 0.843000。
  - **实验结论：** FLaG 的 Spearman 随 Padding 策略发生小幅变化，E3 基本不变。Padding 敏感性不带来性能差异。

[查看本实验详细论述](#detail-10)

<a id="summary-13"></a>

  ### 实验十三（E13）：固定 Global FFT 长度能否改善模型？

  - **实验目的：** 既然 Global FLaG 对 padding 长度敏感，想知道从训练开始固定 FFT 长度是否能改善性能。
  - **实验思路：** 训练和推理时都将 FFT 长度固定为 128，其他模型结构保持不变。
  - **实验结果：** Test Spearman 为 0.841856，相比动态 FFT 的平均配对差为 +0.000728，但只有一个种子领先。
  - **实验结论：** 将 FFT 长度固定为 128 后，Spearman 与动态长度版本接近，没有带来改善。

<a id="summary-15"></a>

  ### 实验十五：通过数学推导解释 Padding 为什么会改变结果

  - **实验目的：** 找到即使 Gate 不变，仅仅改变 FFT 长度也会影响模型输出的原因。
  - **实验思路：** 根据 FLaG 对频谱实部和虚部分别乘不同 Gate 系数的操作，推导它对应的时域变换，并用数值计算验证。
  - **实验结果：** 发现输出不仅包含原位置的 token 特征，还包含循环反转位置的特征。当 FFT 长度改变时，反转位置也会改变。
  - **实验结论：** 实部和虚部采用不同 Gate 系数时，逆 FFT 会引入循环反射项；改变 FFT 长度会改变反射对应的位置，从而改变输出。

[查看本实验详细论述](#detail-15)

<a id="summary-16"></a>

  ### 实验十六（P1）：Padding 的影响到底来自 Gate，还是频谱重建？

  - **实验目的：** 分清 Padding 导致预测变化的真正来源。
  - **实验思路：** 分别控制“生成 Gate 时采用的 FFT 长度”和“应用 Gate、逆 FFT 时采用的长度”，只改变其中一个。 补充实验中，再把实部与虚部 Gate 设为相同，去掉循环反射项。
  - **实验结果：** STSB validation 上，只改变 Gate 生成长度，平均 cosine 预测变化约 \(4.8\times10^{-7}\)；只改变逆变换长度，变化约 0.005520。 去掉循环反射后的输出与固定长度 128 的输出平均 cosine 差约为 0.000295。
  - **实验结论：** Padding 引起的预测差异主要来自应用 Gate 后的逆变换长度，而不是 Gate 的生成长度。取消循环反射后，也得到与固定重建长度相近的预测。

[查看本实验详细论述](#detail-16)

<a id="summary-17"></a>

  ### 实验十七（P2）：Global 和 Local 的差异来自 Gate，还是重建方式？

  - **实验目的：** 找出全局 FFT 与局部 STFT 产生不同句向量的主要原因。
  - **实验思路：** 在相同 checkpoint 下，交叉使用 Global/Local 的 Gate 来源，以及 Global/Local 的频谱处理和重建路径。
  - **实验结果：** 只换 Gate 来源时，预测变化约为 \(10^{-7}\)；更换重建路径后，平均 cosine 变化约为 0.0058 至 0.0060。
  - **实验结论：** 在相同 checkpoint 下，Global 与 Local 的 Gate 来源互换几乎不改变预测，真正产生明显差异的是频谱处理和重建路线。

### 实验十（E10）：Padding 的变化会影响整个测试集的预测性能吗？

**实验设置与评价：** STSB · test · 3 seeds · 固定 checkpoint。

#### 对照问题

E9 的预测变化是否明显影响整个 STSB test 的性能？

#### 实验实施

使用 FLaG/E3 的 **3-seed checkpoint**，每句话只计算一次 RoBERTa hidden，之后采用四种 **pooling 输入长度**，不重新训练：

| 设置 | 处理方式 |
| --- | --- |
| normal | 原始 batch 动态 padding |
| pair_exact | 同一对两句都补到二者较大的有效长度 |
| sentence_exact | 每句分别使用自身有效长度 |
| fixed_128 | 每句统一补零到 128 |

#### 观测结果

**3-seed mean test Spearman**：

| Padding | FLaG | E3 |
| --- | ---: | ---: |
| normal | 0.841128 | 0.843000 |
| pair_exact | 0.841022 | 0.843000 |
| sentence_exact | 0.841288 | 0.843000 |
| fixed_128 | 0.841458 | 0.843000 |

#### 结果解读

Padding 会改变 FLaG 的预测和少量 test Spearman，但未能解释全部 FLaG/E3 性能差异。


四种推理方案的 Global Spearman 数字不完全相同，不能将“敏感性不带来性能差异”理解为数值严格相同；这些差距均较小。

### 实验十五：通过数学推导解释 Padding 为什么会改变结果

**实验设置与评价：** 时域数学等价式与数值核查 · 非模型性能对照。

#### 对照问题

为什么只增加右侧零 padding，global FLaG 的预测也会变化？

#### 实验实施

固定某个样本和 hidden 通道。FLaG 的 gate 在各频率位置共享，但对 FFT **实部、虚部**分别使用乘数 `a`、`b`：

$$
Y[k]=a\,\operatorname{Re}X[k]+ib\,\operatorname{Im}X[k].
$$

逆 FFT 后可以化为：

$$
\boxed{y[t]=\frac{a+b}{2}x[t]+\frac{a-b}{2}x[(-t)\bmod N]}
$$

其中 `N` 为 FFT 长度。第一项是原位置缩放，第二项是**循环反射**。改变 `N` 就会改变反射位置。

#### 观测结果

取 `x=[10,20,30,40]`、`a=1.8,b=1.2`，位置 1 的重建结果：

| FFT 长度 | 反射来源 | `y[1]` |
| --- | --- | ---: |
| N=4 | `x[3]=40` | 42 |
| 右侧补零到 N=8 | `x[7]=0` | 30 |

独立 float64 检查 `N=1–129`，公式和 rFFT/irFFT 的最大误差约 `3.55×10^{-15}`。

#### 结果解读

给定 gate 时，**实虚不对称门控**会产生随 FFT 长度改变的循环反射；实际 gate 也可能随输入改变，因此做 P1 分离两种来源。


等价式在 Gate 乘数固定、对同一条一维序列做 FFT/iFFT 的条件下成立，不等价于完整训练过程的因果结论。

### 实验十六（P1）：Padding 的影响到底来自 Gate，还是频谱重建？

**实验设置与评价：** STSB · validation · 3 seeds · 固定 checkpoint 的门控/重建反事实。

#### 对照问题

padding 导致的预测变化主要来自 gate 变化，还是重建长度变化？

#### 实验实施

使用原始动态 FLaG **3 个 checkpoint**，分别控制生成 gate 的 FFT 长度 `Ng` 和应用 gate、逆 FFT 的长度 `Nr`。`T` 是正常 batch padding 长度。

| 配置 | Ng | Nr |
| --- | ---: | ---: |
| TT（原始） | T | T |
| 128T | 128 | T |
| T128 | T | 128 |
| 128128 | 128 | 128 |

#### 观测结果

STSB validation，**3-seed 相对 TT 的平均绝对 cosine 漂移**：

| 配置 | mean ± std |
| --- | ---: |
| TT | 0 |
| 128T（只换 gate 来源） | \((4.80\pm2.84)\times10^{-7}\) |
| T128（只换重建长度） | **0.005520 ± 0.000805** |
| 128128 | **0.005520 ± 0.000805** |

#### 结果解读

只改变 gate 输入频谱的长度几乎没有影响，当前 padding 敏感性主要来自**重建长度**。

#### 对称门控的补充对照

#### 对照问题

如果强制实、虚 gate 相同，能否重现固定重建长度的预测变化？

#### 实验实施

对同一 checkpoint 令两个实际乘数都等于 `(a+b)/2`，使反射项系数为零，记为 **SYM**。比较 SYM、TT、T128。

#### 观测结果

STSB validation，3-seed 平均绝对 cosine 差：

| 对比 | mean ± std |
| --- | ---: |
| SYM 与 TT | 0.005576 ± 0.000761 |
| T128 与 TT | 0.005520 ± 0.000805 |
| SYM 与 T128 | **0.000295 ± 0.000003** |

#### 结果解读

SYM 和 T128 的预测变化高度接近，支持**循环反射是当前 padding 漂移的主要来源**。固定到 128 不等于每个有效 token 的反射项都为零：位置 0 始终自反。


`SYM` 与 `T128` 的数值接近是已测模型下的预测证据，不表示固定 128 的循环反射项恒为零。

### 实验十七（P2）：Global 和 Local 的差异来自 Gate，还是重建方式？

**实验设置与评价：** STSB · validation · 3 seeds · 固定 checkpoint 的 Global/Local 交叉。

#### 对照问题

从 global FLaG 换成 E12，预测差异主要来自 gate 的频谱来源，还是重建路线？

#### 实验实施

分别加载 FLaG-trained 和 E12-trained 的 **3 个 checkpoint**。对**同一个 checkpoint**交叉更换 gate 的生成来源及实际重建路线：

| 配置 | Gate 来源 | Gate 应用及重建路线 |
| --- | --- | --- |
| GG | Global | Global |
| LG | Local | Global |
| GL | Global | Local |
| LL | Local | Local |

**GL** 表示 global 频谱**只生成 gate**，随后将 gate 应用于 local 频谱，再进行局部逆变换和帧拼接。此处“重建路线”包含频谱组织、逆变换及局部时域拼接，不只是替换 iFFT 函数。

#### 观测结果（1）

STSB validation，**3-seed 平均绝对 cosine 漂移**：

| 权重来源 | 只换 gate：LG−GG | 换重建路线：GL−GG |
| --- | ---: | ---: |
| FLaG-trained | \(2.86\times10^{-7}\) | **0.005770** |
| E12-trained | \(2.14\times10^{-7}\) | **0.005970** |

#### 观测结果（2）

同批 validation 的 **3-seed Spearman 均值**：

| 权重来源 | GG | LG | GL | LL |
| --- | ---: | ---: | ---: | ---: |
| FLaG-trained | 0.867756 | 0.867756 | 0.867590 | 0.867590 |
| E12-trained | 0.867938 | 0.867938 | 0.868096 | 0.868096 |

#### 结果解读

两种频谱生成的句级 gate 几乎相同，global/local 预测差异主要来自**重建路线**。但是，重建路线改变并不代表 Spearman 一定提高。

**区别：** P1 改变 **global 内部的 FFT 长度**；P2 改变 **global/local 的分析与重建方式**。


交换 Gate 与更换**整条重建路径**是不同操作，后者不只改变 iFFT；cosine 漂移不能当作性能提升。
