# STFT 窗口设计与 STSB 配置对照

从全局 FFT 的 Hann 加窗开始，对照局部窗口长度、步长、重叠、位置编码和训练配置下的 STSB 表现。

## 实验总结

<a id="summary-01"></a>

### 实验一（E1）：在 FFT 前增加 Hann 窗，能否改善模型性能？

- **实验目的：** 尝试减小序列两端带来的频谱边界影响，看看能否提高 STSB 的句子相似度预测能力。
- **实验思路：** 使用  FLaG，在 FFT 前对有效 token 特征乘上 Hann 窗函数，再用三个随机种子重新训练。
- **实验结果：** Test Spearman 从 FLaG 的 0.841128 降至 0.837019。
- **实验结论：** 全局 Hann 加窗使 Spearman 下降 0.004109，后续不采用这一加窗方案。

[查看本实验详细论述](#detail-01)

<a id="summary-02"></a>

### 实验二（E2）：把整句 FFT 改成分窗口 FFT，性能会怎样？

- **实验目的：** 验证 STFT 这种局部频域处理方式，是否比 FFT 更适合句子表示。
- **实验思路：** 将句子划分为长度 16、步长 8 的窗口，每两个相邻窗口重叠 8 个 token。所有窗口共同生成一个句级 Gate，再分别进行频域处理和重建。
- **实验结果：** Test Spearman 为 0.842204，比原始 FLaG 高 0.001076，三seed两个更好。
- **实验结论：** 16/8 的局部 FFT 比原始全局 FFT 小幅提高 Spearman，因此继续测试更短的窗口。

[查看本实验详细论述](#detail-02)

<a id="summary-03"></a>

### 实验三（E3）：把窗口缩短，是否更适合短句？

- **实验目的：** 检查更短的局部窗口是否适合 STSB 中长度有限的句子。
- **实验思路：** 将窗口长度改为 8，步长改为 4，其他设置保持一致。
- **实验结果：** Test Spearman 达到 0.843000，比原始 FLaG 高 0.001873，三seed全正向。
- **实验结论：** 8/4 窗口在这组 STSB 实验中取得较高 Spearman，后续先以 E3 为局部模型进行机制分析。

[查看本实验详细论述](#detail-03)

<a id="summary-04"></a>

### 实验四（E4）：给不同窗口加入位置编码有没有帮助？

- **实验目的：** STFT 将句子拆成多个窗口，想验证显式告诉模型“每个窗口位于句子的什么位置”是否有价值。
- **实验思路：** 在 E3 基础上，为窗口的频率特征增加可学习的位置编码，再重新训练。
- **实验结果：** Test Spearman 为 0.842282，低于 E3 的 0.843000。
- **实验结论：** 加入帧位置编码后，Spearman 比 E3 下降 0.000718，因此不保留这一组件。

[查看本实验详细论述](#detail-04)

<a id="summary-05"></a>

### 实验五（E5）：在局部 FFT 中增加 Hann 窗是否有用？

- **实验目的：** 检查局部频域分析中，平滑窗口边界是否能进一步改善效果。
- **实验思路：** 在 E3 基础上使用 periodic Hann 窗，并同时将 center 改为 True。
- **实验结果：** Test Spearman 为 0.843027，与 E3 的 0.843000 几乎一致。
- **实验结论：** 加入局部 Hann 窗并开启 center 后，与 E3 几乎持平，后续继续使用结构更简单的矩形窗。

<a id="summary-11"></a>

  ### 实验十一（E11/E12）：STFT 的窗口重叠探究

  - **实验目的：** 判断相邻窗口的重叠是否真的能够提高模型性能。
  - **实验思路：** 比较窗口长度为 8 和 16，以及半窗口重叠和完全不重叠的四种组合。
  - **实验结果：** 长度 8 时，重叠版本 E3 略好；长度 16 时，不重叠版本 E12 更好。E12 的三种子 Test Spearman 为 0.843419。
  - **实验结论：** 窗口重叠并非获得较好 STSB 结果的必要条件。在长度 16 的设置中，无重叠 E12 更好，因此后续采用 E12。

  ### 实验十二（E12 扩展）：E12 十seed稳定性

  - **实验目的：** 在三种子比较中 E12 较好，进一步通过十个随机种子检查两种模型的实际性能差距。
  - **实验思路：** 在相同 dropout 和 LayerNorm 配置下，将 Global FLaG 与 E12 都扩展到十个随机种子。
  - **实验结果：** E12 平均 Test Spearman 为 0.842739，FLaG 为 0.841559。E12 平均高 0.001180，十个种子中七次领先。
  - **实验结论：** E12 的平均 Spearman 比全局 FLaG 高 0.001180，但两者整体非常接近。

  ### 实验十四（E14）：换成论文文本配置后，STFT 的优势还能保持吗？

  - **实验目的：** 判断此前 STFT 的小幅提升是否只发生在某一种训练配置下。
  - **实验思路：** Global FLaG 和 E12 都采用 dropout 0.1、启用后池化 LayerNorm，重新运行十个种子。
  - **实验结果：** FLaG 的 Test Spearman 为 0.839065，E12 为 0.838944，两者基本持平。

## 实验详细论述

<a id="detail-01"></a>

### 实验一（E1）：在 FFT 前增加 Hann 窗，能否改善模型性能？

**实验设置与评价：** STSB · test Spearman · 3 seeds（0–2）· 重新训练。

#### 对照问题

global FFT 前加 Hann，能否减轻边界影响并改善性能？

#### 实验实施

按**每句话自身有效 token 长度**（包括特殊 token）生成 symmetric Hann，乘到 RoBERTa hidden 上，再执行原 global FFT；padding 仍为零。有效长度 ≤2 时使用全 1 窗口。其他设置与 FLaG 一致，**3 seeds**。

#### 观测结果

Spearman `0.837019 ± 0.002763`，比同 seed FLaG 平均 **−0.004109**。

#### 结果解读

未改善性能，但不能据此排除频谱泄漏，因为加窗同时减弱了边界 token 的输入。


此对照同时改变了边界 token 的输入幅度，不能把指标下降单独解释为频谱泄漏的改变。

### 实验十一（E11/E12）：STFT 的窗口重叠探究

**实验设置与评价：** STSB · test · 3 seeds · 重新训练四种窗口配置。

#### 对照问题

STFT 是否一定需要窗口重叠？

#### 实验实施

比较 win8/win16 与半窗重叠/无重叠，共四种 rect、`center=False` 的 STFT 配置。沿用 E2/E3，并补充重新训练 E11/E12，**每组 3 seeds（0–2）**，其他参数一致。

#### 观测结果

**3-seed test Spearman（mean ± std）**：

| 窗长 | 半窗口重叠 | 无重叠 |
| ---: | ---: | ---: |
| 8 | **E3**：hop4，0.843000 ± 0.001047 | **E11**：hop8，0.842166 ± 0.001423 |
| 16 | **E2**：hop8，0.842204 ± 0.001824 | **E12**：hop16，0.843419 ± 0.000531 |

#### 结果解读

重叠没有一致优势。后续固定使用结构简单的 **E12：rect、win16/hop16、center=False**。


窗口大小与重叠是两个不同因素，结论只限于已测四种组合，且本实验各配置均使用 3 seeds。

### 实验十二（E12 扩展）：E12 十seed稳定性

**实验设置与评价：** STSB · test · 10 seeds（0–9）· 重新训练。

本条是实验十一中 E12 窗口设计的独立十种子稳定性检验；与三种子窗口搜索分开汇报。

将原匹配设置（FLaG/E12 都为 **dropout=0、Norm=True**）扩至 **10 seeds（0–9）**：

| 模型 | test Spearman ↑ | test Pearson ↑ |
| --- | ---: | ---: |
| FLaG | 0.841559 ± 0.003538 | 0.838504 ± 0.003444 |
| E12 | 0.842739 ± 0.003214 | 0.839393 ± 0.003467 |
| 配对 E12−FLaG | **+0.001180 ± 0.002107** | **+0.000889 ± 0.003033** |

Spearman **7/10 seeds** 正向，配对 95% CI 约 `[−0.00033, +0.00269]`。虽然平均差为正，但不足以说明稳定优势。


均值相差 0.001180，仅 7/10 seeds 领先，这组结果只支持小幅平均差异。

### 实验十四（E14）：换成论文文本配置后，STFT 的优势还能保持吗？

**实验设置与评价：** STSB · test · 10 seeds · 统一 dropout / LayerNorm 后重新训练。

#### 对照问题

在论文 text 配置下，E12 相比 FLaG 的早期性能趋势是否仍存在？

#### 实验实施

FLaG 与 E12 都改为 **dropout=0.1、post-pool Norm=True**，其余训练设置匹配，重新训练 **10 seeds（0–9）**。

#### 观测结果

**10-seed test**：

| 模型 | Spearman ↑ | Pearson ↑ |
| --- | ---: | ---: |
| FLaG | 0.839065 ± 0.004154 | 0.834980 ± 0.003942 |
| E12 | 0.838944 ± 0.001882 | 0.834015 ± 0.002119 |
| 配对 E12−FLaG | **−0.000121 ± 0.004039** | **−0.000965 ± 0.003878** |

Spearman **5/10 seeds** 正向。

#### 结果解读

两者基本持平。E12 在 0/有 Norm 下的小幅正向均值没有在这组 0.1/有 Norm 实验中保持。


这里讨论的是本次 10-seed 配对结果；摘要中的后续代码对齐说明保留原样，但不作为性能结论依据。
