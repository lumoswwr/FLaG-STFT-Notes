# STSB：从全局 FFT 改为局部 STFT

> **先看实验概览**：下面逐项说明实验目的、做法、结果和结论。需要复查具体配置、原始指标及计算方法时，再阅读后面的详细实验记录。不同实验的 test、validation 与随机种子信息以详细记录为准。

## 本页实验概览（8 项）

**对应文件：** `docs/stsb/01-experiments.md`

先尝试改变 FFT 的处理方式和窗口，再检查两种模型依赖哪些频率、token 位置以及注意力位置。早期小幅性能提升推动了后续实验，但低频依赖和注意力分配并不等同。

### 实验一（E1）：在 FFT 前增加 Hann 窗，能否改善模型性能？

- **实验目的：** 尝试减小序列两端带来的频谱边界影响，看看能否提高 STSB 的句子相似度预测能力。
- **实验思路：** 保留原始 Global FLaG，在 FFT 前对有效 token 特征乘上 Hann 窗函数，再用三个随机种子重新训练。
- **实验结果：** Test Spearman 从 FLaG 的 0.841128 降至 0.837019。
- **实验结论：** 在本次 STSB 对照中，全局 Hann 加窗使 Spearman 下降 0.004109；后续不采用这一加窗方案。

### 实验二（E2）：把整句 FFT 改成分窗口 FFT，性能会怎样？

- **实验目的：** 验证 STFT 这种局部频域处理方式，是否比原始整句 FFT 更适合句子表示。
- **实验思路：** 将句子划分为长度 16、步长 8 的窗口，每两个相邻窗口重叠 8 个 token。所有窗口共同生成一个句级 Gate，再分别进行频域处理和重建。
- **实验结果：** Test Spearman 为 0.842204，比原始 FLaG 高 0.001076，三个种子中两个更好。
- **实验结论：** 16/8 的局部 FFT 比原始全局 FFT 小幅提高 Spearman，因此继续测试更短的窗口。

### 实验三（E3）：把窗口缩短，是否更适合短句？

- **实验目的：** 检查更短的局部窗口是否适合 STSB 中长度有限的句子。
- **实验思路：** 将窗口长度改为 8，步长改为 4，其他设置保持一致。
- **实验结果：** Test Spearman 达到 0.843000，比原始 FLaG 高 0.001873，三个种子全部正向。
- **实验结论：** 8/4 窗口在这组 STSB 实验中取得较高 Spearman，后续以 E3 为局部模型进行机制分析。

### 实验四（E4）：给不同窗口加入位置编码有没有帮助？

- **实验目的：** STFT 将句子拆成多个窗口，想验证显式告诉模型“每个窗口位于句子的什么位置”是否有价值。
- **实验思路：** 在 E3 基础上，为窗口的频率特征增加可学习的位置编码，再重新训练。
- **实验结果：** Test Spearman 为 0.842282，低于 E3 的 0.843000。
- **实验结论：** 加入帧位置编码后，Spearman 比 E3 下降 0.000718，因此不保留这一组件。

### 实验五（E5）：在局部 FFT 中增加 Hann 窗是否有用？

- **实验目的：** 检查局部频域分析中，平滑窗口边界是否能进一步改善效果。
- **实验思路：** 在 E3 基础上使用 periodic Hann 窗，并同时将 center 改为 True。
- **实验结果：** Test Spearman 为 0.843027，与 E3 的 0.843000 几乎一致。
- **实验结论：** 加入局部 Hann 窗并开启 center 后，与 E3 几乎持平；后续继续使用结构更简单的矩形窗。

### 实验六（E6）：Global FLaG 和 STFT-FLaG 分别依赖哪些频率？

- **实验目的：** 想知道局部 FFT 是否改变了模型对低频和高频信息的依赖。
- **实验思路：** 固定训练好的模型，对 RoBERTa 最后一层内容 token 的特征进行 DCT-II 变换，将频率划成八个频带，每次删除一个频带，观察 Spearman 下降多少。
- **实验结果：** 删除最低频带 B0 的影响最大。FLaG 的平均 Spearman 降幅为 0.146694，E3 为 0.198943。
- **实验结论：** 删除 B0 对两种模型的影响都最大，其中 E3 的 Spearman 降幅更大，表明它在这项频带删除测试中更依赖最低频部分。

### 实验七（E7）：局部 FFT 是否让模型更关注某些 token？

- **实验目的：** 验证 STFT-FLaG 是否比全局 FLaG 更重视句子中的特定位置。
- **实验思路：** 固定训练好的模型，每次将一个内容 token 的隐藏向量置零，观察句对预测平方误差发生多大变化。
- **实验结果：** 两种模型的 token 扰动响应非常接近，句内平均响应分别约为 0.003248 和 0.003155。
- **实验结论：** Global FLaG 与 E3 对 token 位置置零的响应接近，没有观察到局部 FFT 带来更强的特定位置依赖。

### 实验八（E8）：局部 FFT 是否更关注零频率？

- **实验目的：** 比较全局和局部频域模型的注意力，是否更加集中于 DC。
- **实验思路：** 读取 latent attention 权重，比较 DC 频率位置与非 DC 频率位置的平均每位置注意力大小。
- **实验结果：** 三个种子中，E3 的 DC 注意力偏好比都比 Global FLaG 低。例如 seed 0 为 1.305，对应 FLaG 为 2.602。
- **实验结论：** E3 给 DC 位置分配的平均注意力相对更低；这与 E6 中删除低频仍造成较大损失的结果一起说明，注意力大小不能直接当作频带的预测贡献。

**本篇小结：** 局部窗口一度取得略高 Spearman；加入 Hann 窗或帧位置编码没有进一步改善，E3 也没有表现出更强的 token 位置选择性。

## 详细实验记录与数据

本页使用 **STSB**。E1–E5 重新训练，使用 **seeds 0、1、2**，结果为 **test Spearman / Pearson（mean ± std）**；E6–E8 则使用这些 seed 的**已训练 FLaG/E3 checkpoint** 做分析，不重新训练。共同配置见[实验设置](../methods.md)。

### E1–E5 配置及结果对照

除表内变化，统一采用 **dropout=0、post-pool Norm=True**，8 latents、4 heads、3 epochs。

| 模型 | 与 global FLaG 的主要区别 | test Spearman ↑ | test Pearson ↑ |
| --- | --- | ---: | ---: |
| FLaG | 整句 FFT | 0.841128 ± 0.002177 | 0.836765 ± 0.001782 |
| **E1** | Global FFT 前加 symmetric Hann | 0.837019 ± 0.002763 | 0.836682 ± 0.000282 |
| **E2** | STFT：rect，win16/hop8 | 0.842204 ± 0.001824 | 0.837783 ± 0.003514 |
| **E3** | STFT：rect，win8/hop4 | 0.843000 ± 0.001047 | 0.838685 ± 0.001421 |
| **E4** | E3 + learned frame position | 0.842282 ± 0.001834 | 未汇总 |
| **E5** | E3 + periodic Hann，center=True | 0.843027 ± 0.000593 | 0.838083 ± 0.002720 |

E2/E3 使用 `center=False`，均只生成**一个句级 gate**；E5 **同时改变了窗函数与 center 设置**，不能将变化单独归因于 Hann。

### E1：Global Hann

**具体问题：** global FFT 前加 Hann，能否减轻边界影响并改善性能？

**具体做法与参数：** 按**每句话自身有效 token 长度**（包括特殊 token）生成 symmetric Hann，乘到 RoBERTa hidden 上，再执行原 global FFT；padding 仍为零。有效长度 ≤2 时使用全 1 窗口。其他设置与 FLaG 一致，**3 seeds**。

**详细结果：** Spearman `0.837019 ± 0.002763`，比同 seed FLaG 平均 **−0.004109**。

**结果说明：** 未改善性能，但不能据此排除频谱泄漏，因为加窗同时减弱了边界 token 的输入。

### E2：首次改为 STFT（16/8）

**具体问题：** 把整句 FFT 换成局部 STFT 是否改善结果？

**具体做法与参数：** rect 窗，`win=16,hop=8,center=False`，相邻帧重叠 8 token。所有有效帧的频率 token 共同生成一个句级 gate；逐帧逆变换并重建，**3 seeds**。

**详细结果：** Spearman `0.842204 ± 0.001824`，比 FLaG 平均 **+0.001076**，2/3 seeds 正向。

**结果说明：** 观察到小幅正向结果，继续检查窗口大小。

### E3：缩短窗口（8/4）

**具体问题：** 部分短句在 win16 下只有一个有效帧，缩短窗口后效果如何？

**具体做法与参数：** 延续 E2 的做法，改为 `win=8,hop=4`，其余不变，**3 seeds**。

**详细结果：** Spearman `0.843000 ± 0.001047`；比 FLaG 平均 **+0.001873**（3/3 正向），比 E2 平均 **+0.000796**。

**结果说明：** 早期观察到小幅改善，因此选择 E3 进行 E6–E8 机制分析；3 seeds 不能证明稳定优势。

### E4：添加帧位置编码

**具体问题：** 局部帧的位置顺序信息是否有帮助？

**具体做法与参数：** 在 E3 的频率 token 进入 latent attention 前，加 **learned frame positional encoding**；窗长及其他配置不变，重新训练 **3 seeds**。

**详细结果：** Spearman `0.842282 ± 0.001834`，比 E3 平均 **−0.000718**。

**结果说明：** 这种帧位置编码没有带来改善，后续不采用。

### E5：局部 Hann

**具体问题：** 给局部帧加窗是否继续改善 E3？

**具体做法与参数：** 在 E3 的 win8/hop4 上，将 rect 换成 **periodic Hann**，并同时设 `center=True`；重新训练 **3 seeds**。

**详细结果：** Spearman `0.843027 ± 0.000593`，比 E3 平均 **+0.000027**。

**结果说明：** 基本持平，后续优先使用更简单的 rect 实现。本实验未单独拆分 Hann 与 centering 的作用。

---

### E6：频带 Knockout

**具体问题：** FLaG 与 E3 分别依赖哪些输入频带？

**具体做法与参数：** 固定两组已训练 checkpoint（**seeds 0–2**）。对 RoBERTa **最后一层的内容 token hidden** 沿位置做 DCT-II，按几何比例划分为 **8 个频带 B0–B7**（B0 为最低频）；每次只将一段的系数置零、逆 DCT，再交给原模型预测。特殊 token 不变。只使用**句对两侧均至少有 8 个内容 token** 的 test 子集。

频带的重要性用 **Spearman 降幅**衡量：

$$
\Delta\rho_b=\rho_{\mathrm{before}}-\rho_{\mathrm{after},b}.
$$

**详细结果：** B0 引起的平均 Spearman 降幅最大：FLaG **0.146694**，E3 **0.198943**。

**结果说明：** 两个模型都对最低频敏感；E3 与 FLaG 的相对差异随 seed 变化，不能据此确认 E3 的性能变化由低频造成。

### E7：Token Hidden Knockout

**具体问题：** E3 是否对特定 token 位置更敏感？

**具体做法与参数：** 固定 FLaG/E3 的 **3-seed checkpoint**。逐个把**内容 token 的最后一层 hidden 向量置零**，其他 token、特殊 token 和 mask 不变，重新计算句对 cosine。

令原预测为 `s`，扰动后为 `s'`，标签为 `y`（原始分数除以 5）。对每个位置计算**绝对平方误差变化**：

$$
R_{\text{token}}=\left|(s'-y)^2-(s-y)^2\right|.
$$

先按相同句子、相同 token 位置对齐三个 seed 的响应取平均，再统计句内位置分布。以下数字**不是** Spearman。

**详细结果：** STSB test，3-seed 聚合：

| 指标 | FLaG | E3 |
| --- | ---: | ---: |
| 句内平均响应的跨句均值 | 0.003248 | 0.003155 |
| 句内最大响应的跨句均值 | 0.007714 | 0.007616 |
| 句内位置响应标准差的跨句均值 | 0.00195551 | 0.00195521 |

**结果说明：** 两组的 token 位置响应接近，没有观察到 E3 更强的位置选择性。

### E8：DC Attention 偏好比

**具体问题：** E3 是否比 global FLaG 更偏向 DC（零频）？

**具体做法与参数：** 固定 **3-seed checkpoint**，从正常 forward 中读取 latent attention 权重，先在 latent queries（以及需要时的 attention heads）上取平均。FLaG 的全局 `k=0` 是 DC；E3 将**每个有效局部帧**的 `k=0` 都计为 DC。

对每句话，分别计算 DC 与非 DC 的**每 token 平均注意力**，再求比值：

$$
r_{\mathrm{DC}}=
\frac{\left(\sum_{k\in\mathrm{DC}}A_k\right)/N_{\mathrm{DC}}}
{\left(\sum_{k\in\mathrm{nonDC}}A_k\right)/N_{\mathrm{nonDC}}+10^{-12}}.
$$

`r_DC>1` 表示**平均每个 DC token** 的注意力较高。表中的数值为每个 seed 在 **STSB test 句子**上的平均偏好比，不是 DC 能量占比。

**详细结果：**

| Seed | FLaG | E3 |
| ---: | ---: | ---: |
| 0 | 2.602 | 1.305 |
| 1 | 1.586 | 1.213 |
| 2 | 2.553 | 1.625 |

**结果说明：** E3 在三个 seed 上的 DC attention 偏好比都较低。但 attention 分配与 E6 的 knockout 性能敏感性**不是同一个指标**，不能仅凭偏好比判断 DC 的实际重要性。
