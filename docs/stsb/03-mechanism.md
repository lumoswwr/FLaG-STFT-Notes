# STSB：解释 Global/Local 输出差异

> **先看实验概览**：下面逐项说明实验目的、做法、结果和结论。需要复查具体配置、原始指标及计算方法时，再阅读后面的详细实验记录。不同实验的 test、validation 与随机种子信息以详细记录为准。

## 本页实验概览（3 项）

**对应文件：** `docs/stsb/03-mechanism.md`

前面的 Padding 实验发现 Global FLaG 的输出会变化。这一组不再重新训练，而是逐步控制 FFT 长度、Gate 来源和逆变换方式，找出变化究竟来自哪里。

### 实验十五：通过数学推导解释 Padding 为什么会改变结果

- **实验目的：** 找到即使 Gate 不变，仅仅改变 FFT 长度也会影响模型输出的原因。
- **实验思路：** 根据 FLaG 对频谱实部和虚部分别乘不同 Gate 系数的操作，推导它对应的时域变换，并用数值计算验证。
- **实验结果：** 发现输出不仅包含原位置的 token 特征，还包含循环反转位置的特征。当 FFT 长度改变时，反转位置也会改变。公式在 float64 检查中的最大误差约为 \(3.55\times10^{-15}\)。
- **实验结论：** 实部和虚部采用不同 Gate 系数时，逆 FFT 会引入循环反射项；改变 FFT 长度会改变反射对应的位置，从而改变输出。

### 实验十六（P1）：Padding 的影响到底来自 Gate，还是频谱重建？

- **实验目的：** 分清 Padding 导致预测变化的真正来源。
- **实验思路：** 分别控制“生成 Gate 时采用的 FFT 长度”和“应用 Gate、逆 FFT 时采用的长度”，只改变其中一个。 补充实验中，再把实部与虚部 Gate 设为相同，去掉循环反射项。
- **实验结果：** STSB validation 上，只改变 Gate 生成长度，平均 cosine 预测变化约 \(4.8\times10^{-7}\)；只改变逆变换长度，变化约 0.005520。 去掉循环反射后的输出与固定长度 128 的输出平均 cosine 差约为 0.000295。
- **实验结论：** Padding 引起的预测差异主要来自应用 Gate 后的逆变换长度，而不是 Gate 的生成长度；取消循环反射后，也得到与固定重建长度相近的预测。

### 实验十七（P2）：Global 和 Local 的差异来自 Gate，还是重建方式？

- **实验目的：** 找出全局 FFT 与局部 STFT 产生不同句向量的主要原因。
- **实验思路：** 在相同 checkpoint 下，交叉使用 Global/Local 的 Gate 来源，以及 Global/Local 的频谱处理和重建路径。
- **实验结果：** 只换 Gate 来源时，预测变化约为 \(10^{-7}\)；更换重建路径后，平均 cosine 变化约为 0.0058 至 0.0060。
- **实验结论：** 在相同 checkpoint 下，Global 与 Local 的 Gate 来源互换几乎不改变预测，真正产生明显差异的是频谱处理和重建路线。

**本篇小结：** 实虚部 Gate 不同会产生循环反射；Padding 与 Global/Local 的预测变化主要由重建路线引起，而不是 Gate 来源。

## 详细实验记录与数据

本页在**固定 checkpoint** 下分析预测变化，不重新训练。P1/P2 均使用 **STSB validation、seeds 0–2**；指标“平均绝对预测漂移”指同一句对两种处理方式下 cosine 预测差的绝对值均值，**不是 Spearman 差**。

### 循环反射的时域推导

**具体问题：** 为什么只增加右侧零 padding，global FLaG 的预测也会变化？

**具体做法与参数：** 固定某个样本和 hidden 通道。FLaG 的 gate 在各频率位置共享，但对 FFT **实部、虚部**分别使用乘数 `a`、`b`：

$$
Y[k]=a\,\operatorname{Re}X[k]+ib\,\operatorname{Im}X[k].
$$

逆 FFT 后可以化为：

$$
\boxed{y[t]=\frac{a+b}{2}x[t]+\frac{a-b}{2}x[(-t)\bmod N]}
$$

其中 `N` 为 FFT 长度。第一项是原位置缩放，第二项是**循环反射**。改变 `N` 就会改变反射位置。

**详细结果：** 取 `x=[10,20,30,40]`、`a=1.8,b=1.2`，位置 1 的重建结果：

| FFT 长度 | 反射来源 | `y[1]` |
| --- | --- | ---: |
| N=4 | `x[3]=40` | 42 |
| 右侧补零到 N=8 | `x[7]=0` | 30 |

独立 float64 检查 `N=1–129`，公式和 rFFT/irFFT 的最大误差约 `3.55×10^{-15}`。

**结果说明：** 给定 gate 时，**实虚不对称门控**会产生随 FFT 长度改变的循环反射；实际 gate 也可能随输入改变，因此做 P1 分离两种来源。

### P1：Gate 长度 × 重建长度

**具体问题：** padding 导致的预测变化主要来自 gate 变化，还是重建长度变化？

**具体做法与参数：** 使用原始动态 FLaG **3 个 checkpoint**，分别控制生成 gate 的 FFT 长度 `Ng` 和应用 gate、逆 FFT 的长度 `Nr`。`T` 是正常 batch padding 长度。

| 配置 | Ng | Nr |
| --- | ---: | ---: |
| TT（原始） | T | T |
| 128T | 128 | T |
| T128 | T | 128 |
| 128128 | 128 | 128 |

**详细结果：** STSB validation，**3-seed 相对 TT 的平均绝对 cosine 漂移**：

| 配置 | mean ± std |
| --- | ---: |
| TT | 0 |
| 128T（只换 gate 来源） | \((4.80\pm2.84)\times10^{-7}\) |
| T128（只换重建长度） | **0.005520 ± 0.000805** |
| 128128 | **0.005520 ± 0.000805** |

**结果说明：** 只改变 gate 输入频谱的长度几乎没有影响，当前 padding 敏感性主要来自**重建长度**。

### P1 补充：去掉反射项

**具体问题：** 如果强制实、虚 gate 相同，能否重现固定重建长度的预测变化？

**具体做法与参数：** 对同一 checkpoint 令两个实际乘数都等于 `(a+b)/2`，使反射项系数为零，记为 **SYM**。比较 SYM、TT、T128。

**详细结果：** STSB validation，3-seed 平均绝对 cosine 差：

| 对比 | mean ± std |
| --- | ---: |
| SYM 与 TT | 0.005576 ± 0.000761 |
| T128 与 TT | 0.005520 ± 0.000805 |
| SYM 与 T128 | **0.000295 ± 0.000003** |

**结果说明：** SYM 和 T128 的预测变化高度接近，支持**循环反射是当前 padding 漂移的主要来源**。固定到 128 不等于每个有效 token 的反射项都为零：位置 0 始终自反。

### P2：Global / Local 的 Gate 与重建

**具体问题：** 从 global FLaG 换成 E12，预测差异主要来自 gate 的频谱来源，还是重建路线？

**具体做法与参数：** 分别加载 FLaG-trained 和 E12-trained 的 **3 个 checkpoint**。对**同一个 checkpoint**交叉更换 gate 的生成来源及实际重建路线：

| 配置 | Gate 来源 | Gate 应用及重建路线 |
| --- | --- | --- |
| GG | Global | Global |
| LG | Local | Global |
| GL | Global | Local |
| LL | Local | Local |

**GL** 表示 global 频谱**只生成 gate**，随后将 gate 应用于 local 频谱，再进行局部逆变换和帧拼接。此处“重建路线”包含频谱组织、逆变换及局部时域拼接，不只是替换 iFFT 函数。

**预测变化：** STSB validation，**3-seed 平均绝对 cosine 漂移**：

| 权重来源 | 只换 gate：LG−GG | 换重建路线：GL−GG |
| --- | ---: | ---: |
| FLaG-trained | \(2.86\times10^{-7}\) | **0.005770** |
| E12-trained | \(2.14\times10^{-7}\) | **0.005970** |

**对应评价指标：** 同批 validation 的 **3-seed Spearman 均值**：

| 权重来源 | GG | LG | GL | LL |
| --- | ---: | ---: | ---: | ---: |
| FLaG-trained | 0.867756 | 0.867756 | 0.867590 | 0.867590 |
| E12-trained | 0.867938 | 0.867938 | 0.868096 | 0.868096 |

**结果说明：** 两种频谱生成的句级 gate 几乎相同，global/local 预测差异主要来自**重建路线**。但是，重建路线改变并不代表 Spearman 一定提高。

**区别：** P1 改变 **global 内部的 FFT 长度**；P2 改变 **global/local 的分析与重建方式**。
