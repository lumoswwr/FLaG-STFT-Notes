# 循环反射的时域推导与 P1/P2

## 循环反射的时域推导

**Q：** E9/E10 已发现，仅改变 pooling 输入的右 padding 长度就会使 FLaG 预测变化。为理解这一现象，检查实部、虚部分别乘 gate 后，逆 FFT 在 token 位置轴上对应什么操作。

### 1. 输入与实虚 gate

先考虑一个句子、一个 hidden 通道，省略 batch 和通道下标。令 $x[t]$ 为进入 FFT 的实值序列，$N$ 为变换长度，$t=0,\ldots,N-1$；有效长度以外的位置补零。$X[k]$ 为其 $N$ 点 DFT。

$$
X[k] = \sum_{t=0}^{N-1} x[t] e^{-i2\pi kt/N}
$$

当前实现生成一个通道 gate，并在所有频率位置共享。令实部、虚部的实际乘数分别为 $a,b$；开启 residual gate 时，它们包含“$1+\mathrm{sigmoid}$ 输出”。

$$
a = 1 + g_{Re}, \qquad b = 1 + g_{Im}
$$

$$
Y[k] = a\,\mathrm{Re}(X[k]) + i b\,\mathrm{Im}(X[k])
$$

这里 $a,b$ 可以随输入句子及 hidden 通道变化，但对频率 $k$ 不变。$Y[k]$ 表示施加 gate 后的频谱。

### 2. 将频谱改写为原频谱与其共轭

$$
\mathrm{Re}(X[k]) = \frac{X[k] + \overline{X[k]}}{2},
\qquad
i\,\mathrm{Im}(X[k]) = \frac{X[k] - \overline{X[k]}}{2}
$$

代入 gate 操作并合并同类项：

$$
Y[k]
= \frac{a+b}{2}X[k]
+ \frac{a-b}{2}\overline{X[k]}
$$

令

$$
\alpha = \frac{a+b}{2},
\qquad
\beta = \frac{a-b}{2},
$$

则

$$
Y[k] = \alpha X[k] + \beta \overline{X[k]}.
$$

### 3. 逆变换得到循环反射

由于 $x[t]$ 为实值序列，频谱共轭的逆 DFT 等于原序列的循环反射：

$$
\mathcal{F}_N^{-1}\{\overline{X[k]}\}[t]
= x[(-t) \bmod N]
$$

利用逆变换的线性性，得到核心恒等式：

$$
y[t]
= \alpha x[t]
+ \beta x[(-t) \bmod N]
$$

### 4. 公式含义与通道形式

第一项是原位置 hidden 的缩放；第二项是循环反射位置 hidden 的混入。恢复通道下标 $d$ 后：

$$
y[t,d]
= \frac{a_d+b_d}{2}x[t,d]
+ \frac{a_d-b_d}{2}x[(-t) \bmod N,d]
$$

$y$ 是逆 FFT 后、最终时间维聚合前的 token hidden，不是最终句向量。代码采用 rFFT/irFFT 保存和重建实值信号的半谱，与上面的完整 DFT 表达等价。

循环反射不同于普通倒序。以 $N=4$ 为例，位置 0、1、2、3 分别映射到 0、3、2、1：

$$
[x_0,x_1,x_2,x_3]
\rightarrow
[x_0,x_3,x_2,x_1]
$$

当 $a=b$ 时，$\beta=0$，反射项消失，重建只剩通道缩放 $y[t]=a x[t]$。

### 5. Padding 如何改变反射来源

取固定 gate 的示例：$x=[10,20,30,40]$，$a=1.8$，$b=1.2$，因此 $\alpha=1.5,\beta=0.3$。未补零时 $N=4$，位置 1 的反射来源是位置 3：

$$
y[1] = 1.5\times20 + 0.3\times40 = 42
$$

在同一序列后补四个零，$N=8$。此时位置 1 的反射来源变为位置 7，属于零 padding：

$$
y[1] = 1.5\times20 + 0.3\times0 = 30
$$

有效 hidden 和 gate 均未变化，仅改变 $N$，就改变了反射来源及重建结果。因此，padding 可通过“变换长度 → 反射索引 → 重建 hidden”这条路径影响模型输出。

更一般地，若有效位置为 $0,\ldots,L-1$，其余为零，且 $N\ge 2L-1$，则所有有效 $t>0$ 的反射位置都落入 padding：

$$
y[0] = a x[0],
\qquad
y[t] = \alpha x[t] \quad (1\le t<L)
$$

位置 0 自反，因此仍使用乘数 $a$。在本实验中该位置对应 BOS。

### 6. 实现检查与结论

独立 float64 数值检查比较“rFFT → 实虚乘 gate → irFFT”和上述时域公式。全局恒等式在 $N=1,\ldots,129$ 的检查中，最大绝对误差约为 $3.55\times10^{-15}$，两种计算在数值精度范围内一致。

**C：** 跨频率共享的实虚 gate 在给定 gate 时，等价于通道缩放与循环反射的混合，为 padding 敏感性提供了结构解释。gate 本身仍由输入生成，不能据此称整个网络为固定线性模型，也不能认定模型未使用频域信息。长度变化还可能影响 gate 的生成；哪条路径主导实际预测漂移，需要后续 P1 交叉验证。

## P1

**Q：** 上述推导中，padding 改变可能通过两种方式改变最后结果：

1. 改变用于生成 gate 的频谱，进而改变实部、虚部乘数 $a,b$；
2. 改变循环反射位置，即使 $a,b$ 不变，重建结果也可能改变。

**M：** 规定：

- $N_g$：生成 gate 的 FFT 长度

- $N_r$：重建时 FFT 长度

  | 配置   | $N_g$ | $N_r$ |
  | ------ | ----: | ----: |
  | TT     |     T |     T |
  | 128T   |   128 |     T |
  | T128   |     T |   128 |
  | 128128 |   128 |   128 |

**R：**

| 配置   | 相对TT的绝对预测漂移,三seed均值±标准差 |
| ------ | -------------------------------------: |
| TT     |                                      0 |
| 128T   |       $(4.80 \pm 2.84) \times 10^{-7}$ |
| T128   |                      0.005520±0.000805 |
| 128128 |                      0.005520±0.000805 |

**C：** 可以看出 FLaG 预测漂移主要来自 reconstruction 过程中 FFT 长度改变。Padding 对 $a,b$ 的影响十分小。

## P1 补充

**Q：** P1 中将 reconstruction 时 padding 长度固定为 128，使反射项数值为 0。那么如果反射项系数为 0，结论是否保持一致？

**M：** 令 $a=b$，使反射项系数变为 0，命名为 SYM（对称实验）。

**R：**

| 比较      | 平均绝对预测差异 |
| --------- | ---------------: |
| SYM与TT   |         0.005576 |
| T128与TT  |         0.005520 |
| SYM与T128 |         0.000295 |

**C：** SYM 与 T128 高度一致，结论保持不变：反射混合是当前预测漂移来源。

## P2

**Q：** 继续探究从 global 换到 local 时，预测变化来自 gate 还是重建。

**M：**

- G:global,整句全局FFT
- L:local,E12的16/16局部STFT
- 第一个字母:生成gate的频谱来源
- 第二个字母:应用gate并重建hidden的方式

**R：**

| 参数来源 | GG       | LG       | GL       | LL       |
| -------- | -------- | -------- | -------- | -------- |
| FLaG     | 0.867756 | 0.867756 | 0.867590 | 0.867590 |
| E12      | 0.867938 | 0.867938 | 0.868096 | 0.868096 |

**C：** 结果清晰展示：只换 gate 频谱来源，gate 不变；只换 reconstruction，会产生与完整切换到 local 几乎相同的预测漂移。但是改变 reconstruction 不意味着成绩提高。
