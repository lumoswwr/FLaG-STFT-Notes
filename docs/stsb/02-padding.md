# STSB：E9–E14 Padding 与配置

## E9

**Q：** 频率 token DC 分析没有得到较为关键信息，因此进一步考虑 STFT 的提升是否来自对外部 padding 更稳定。

**M：** 取长度不超过 16 的句子，分别 padding 到 16、24、32、64、128。

**R：** 补到 128 时：

| 相对各句精确长度的预测漂移 |     FLaG |   E3 |
| -------------------------- | -------: | ---: |
| 平均绝对相似度变化         | 0.006003 |    0 |
| 最大绝对相似度变化         | 0.035915 |    0 |

**C：** FLaG 对 padding 敏感。

## E10

**Q：** 承接 E9，探索数据集上的 padding 是否会影响最终预测。

**M：** 加载 FLaG 以及 E3（`win=8, hop=4`）checkpoint，采用四种处理方式。

|                |                            |
| -------------- | -------------------------- |
| normal         | 保持原来的batch padding    |
| pair_exact     | 句对两侧都适用             |
| sentence_exact | 每句话分别使用自身有效长度 |
| fixed_128      | 所有句子统一补到128        |

**R：**

| 推理约定       | FLaG三seed平均Spearman |       E3 |
| -------------- | ---------------------: | -------: |
| normal         |               0.841128 | 0.843000 |
| pair_exact     |               0.841022 | 0.843000 |
| sentence_exact |               0.841288 | 0.843000 |
| fixed_128      |               0.841458 | 0.843000 |

**C：** 有影响，但不是主要导致 FLaG 与 STFT 差距的原因；同时进一步确认 STFT 对 padding 不敏感，FLaG 反之。

## E12

**Q：** 尝试窗口不重叠。

**M：** 设置窗口大小为 16 或 8，重叠设置为半个窗口或不重叠。

**R：**

| 窗口大小 |                    有重叠:每次移动半个窗口 |                      无重叠:每次移动整个窗口 |
| -------- | -----------------------------------------: | -------------------------------------------: |
| 8        |  E3:`win=8`,`hop=4`<br />0.843000±0.001047 |   E11:`win=8`,`hop=8`<br />0.842116±0.001423 |
| 16       | E2:`win=16`,`hop=8`<br />0.842204±0.001824 | E12:`win=16`,`hop=16`<br />0.843419±0.000531 |

**C：** 后续模型全部使用 `win=16 / hop=16`。

## E13

**Q：** E10 只在推理采用固定 padding，训练时仍动态。探究从训练开始固定 padding 长度。

**M：** 采用 `fixed_128` padding 训练 FLaG，3 seed。

**R：** 0.841856 ± 0.001000；相对 FLaG +0.000728 ± 0.003079，仅 1/3 正向。

**C：** FLaG 对 padding 敏感，但固定 padding 不代表模型表现更好。

## E14

> 此处E14是在Sprint数据集上发现dropout norm设置对模型有影响的补充

**Q：** 在 STSB 数据集补充 `dropout=0.1, norm=True`，也就是对齐原论文配置。

**R：**

- FLaG：0.839065 ± 0.004154
- E12：0.838944 ± 0.001882
- E12 − FLaG：−0.000121 ± 0.004039，5/10 seed 为正

**C：** 在统一 `dropout=0 + Norm` 时 STSB 曾观察到 E12 的轻微正向趋势，但在论文 text 配置 `0.1 + Norm` 下该趋势消失。
