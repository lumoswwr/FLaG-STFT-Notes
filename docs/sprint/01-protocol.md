| 项目     | STSB                     | Sprint                     |
| -------- | ------------------------ | -------------------------- |
| RoBERTa  | 参与微调                 | 冻结                       |
| pooling  | 训练                     | 重新初始化并训练           |
| 输出     | 预测相似度               | 判断是否恢复               |
| 分类head | 直接用cosine计算回归损失 | cosine后增加可训练分类head |
| 损失     | MSE                      | BCEWithLogitsLoss          |
