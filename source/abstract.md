### 实验一（E1）：在 FFT 前增加 Hann 窗，能否改善模型性能？

- **实验目的：** 尝试减小序列两端带来的频谱边界影响，看看能否提高 STSB 的句子相似度预测能力。
- **实验思路：** 使用  FLaG，在 FFT 前对有效 token 特征乘上 Hann 窗函数，再用三个随机种子重新训练。
- **实验结果：** Test Spearman 从 FLaG 的 0.841128 降至 0.837019。
- **实验结论：** 全局 Hann 加窗使 Spearman 下降 0.004109，后续不采用这一加窗方案。

### 实验二（E2）：把整句 FFT 改成分窗口 FFT，性能会怎样？

- **实验目的：** 验证 STFT 这种局部频域处理方式，是否比 FFT 更适合句子表示。
- **实验思路：** 将句子划分为长度 16、步长 8 的窗口，每两个相邻窗口重叠 8 个 token。所有窗口共同生成一个句级 Gate，再分别进行频域处理和重建。
- **实验结果：** Test Spearman 为 0.842204，比原始 FLaG 高 0.001076，三seed两个更好。
- **实验结论：** 16/8 的局部 FFT 比原始全局 FFT 小幅提高 Spearman，因此继续测试更短的窗口。

### 实验三（E3）：把窗口缩短，是否更适合短句？

- **实验目的：** 检查更短的局部窗口是否适合 STSB 中长度有限的句子。
- **实验思路：** 将窗口长度改为 8，步长改为 4，其他设置保持一致。
- **实验结果：** Test Spearman 达到 0.843000，比原始 FLaG 高 0.001873，三seed全正向。
- **实验结论：** 8/4 窗口在这组 STSB 实验中取得较高 Spearman，后续先以 E3 为局部模型进行机制分析。

### 实验四（E4）：给不同窗口加入位置编码有没有帮助？

- **实验目的：** STFT 将句子拆成多个窗口，想验证显式告诉模型“每个窗口位于句子的什么位置”是否有价值。
- **实验思路：** 在 E3 基础上，为窗口的频率特征增加可学习的位置编码，再重新训练。
- **实验结果：** Test Spearman 为 0.842282，低于 E3 的 0.843000。
- **实验结论：** 加入帧位置编码后，Spearman 比 E3 下降 0.000718，因此不保留这一组件。

### 实验五（E5）：在局部 FFT 中增加 Hann 窗是否有用？

- **实验目的：** 检查局部频域分析中，平滑窗口边界是否能进一步改善效果。
- **实验思路：** 在 E3 基础上使用 periodic Hann 窗，并同时将 center 改为 True。
- **实验结果：** Test Spearman 为 0.843027，与 E3 的 0.843000 几乎一致。
- **实验结论：** 加入局部 Hann 窗并开启 center 后，与 E3 几乎持平，后续继续使用结构更简单的矩形窗。

### 实验六（E6）：Global FLaG 和 STFT-FLaG 分别依赖哪些频率？

- **实验目的：** 探究局部 FFT 是否改变了模型对低频和高频信息的依赖。
- **实验思路：** 固定训练好的模型，对 RoBERTa 最后一层内容 token 的特征进行 DCT-II 变换，将频率划成八个频带，每次删除一个频带，观察 Spearman 下降多少。
- **实验结果：** 删除最低频带 B0 的影响最大。FLaG 的平均 Spearman 降幅为 0.146694，E3 为 0.198943。
- **实验结论：** 删除 B0 对两种模型的影响都最大，其中 E3 的 Spearman 降幅更大，表明它在这项频带删除测试中更依赖最低频部分。

### 实验七（E7）：局部 FFT 是否让模型更关注某些 token？

- **实验目的：** 验证 STFT-FLaG 是否比全局 FLaG 更重视句子中的特定位置。
- **实验思路：** 固定训练好的模型，每次将一个内容 token 的隐藏向量置零，观察句对预测平方误差发生多大变化。
- **实验结果：** 两种模型的 token 扰动响应非常接近，句内平均响应分别约为 0.003248 和 0.003155。
- **实验结论：** Global FLaG 与 E3 对 token 位置置零的响应接近，没有观察到局部 FFT 带来更强的特定位置依赖。

### 实验八（E8）：局部 FFT 是否更关注零频率？

- **实验目的：** 比较全局和局部频域模型的注意力，是否更加集中于 DC。

- **实验思路：** 读取 latent attention 权重，比较 DC 频率位置与非 DC 频率位置的平均每位置注意力大小。

- **实验结果：** 三个种子中，E3 的 DC 注意力偏好比都比 Global FLaG 低。

- **实验结论：** E3 给 DC 位置分配的平均注意力相对更低

  ### 实验九（E9）：只增加 Padding，为什么预测会变化？

  - **实验目的：** 检查模型是否会受到无效 padding 位置的影响。
  - **实验思路：** 固定 RoBERTa 已计算好的有效 token 特征，只在后面增加零 padding，分别比较 FLaG 和 E3(STFT) 的预测结果。
  - **实验结果：** 当补零长度达到 128 时，Global FLaG 的平均 cosine 预测变化约为 0.006003，最大为 0.035915；E3 几乎没有变化。
  - **实验结论：** 仅在有效 token 后增加零 Padding，就会改变 FLaG 的输出，E3 对这项操作不敏感。

  ### 实验十（E10）：Padding 的变化会影响整个测试集的预测性能吗？

  - **实验目的：** 验证 E9 中观察到的预测变化，是否进一步影响 STSB 的整体 Spearman。
  - **实验思路：** 使用动态 padding、句对统一长度、每句精确长度以及统一长度 128 四种方式进行推理，不重新训练模型。
  - **实验结果：** FLaG 的平均 Test Spearman 在 0.841022 至 0.841458 之间变化，E3 基本保持 0.843000。
  - **实验结论：** FLaG 的 Spearman 随 Padding 策略发生小幅变化，E3 基本不变。Padding 敏感性不带来性能差异。

  ### 实验十一（E11/E12）：STFT 的窗口重叠探究

  - **实验目的：** 判断相邻窗口的重叠是否真的能够提高模型性能。
  - **实验思路：** 比较窗口长度为 8 和 16，以及半窗口重叠和完全不重叠的四种组合。
  - **实验结果：** 长度 8 时，重叠版本 E3 略好；长度 16 时，不重叠版本 E12 更好。E12 的三种子 Test Spearman 为 0.843419。
  - **实验结论：** 窗口重叠并非获得较好 STSB 结果的必要条件。在长度 16 的设置中，无重叠 E12 更好，因此后续采用 E12。

  ### 实验十二（E12 扩展）：E12 十seed稳定性

  - **实验目的：** 在三种子比较中 E12 较好，进一步通过十个随机种子检查两种模型的实际性能差距。
  - **实验思路：** 在相同 dropout 和 LayerNorm 配置下，将 Global FLaG 与 E12 都扩展到十个随机种子。
  - **实验结果：** E12 平均 Test Spearman 为 0.842739，FLaG 为 0.841559。E12 平均高 0.001180，十个种子中七次领先。
  - **实验结论：** E12 的平均 Spearman 比全局 FLaG 高 0.001180，但两者整体非常接近。

  ### 实验十三（E13）：固定 Global FFT 长度能否改善模型？

  - **实验目的：** 既然 Global FLaG 对 padding 长度敏感，想知道从训练开始固定 FFT 长度是否能改善性能。
  - **实验思路：** 训练和推理时都将 FFT 长度固定为 128，其他模型结构保持不变。
  - **实验结果：** Test Spearman 为 0.841856，相比动态 FFT 的平均配对差为 +0.000728，但只有一个种子领先。
  - **实验结论：** 将 FFT 长度固定为 128 后，Spearman 与动态长度版本接近，没有带来改善。

  ### 实验十四（E14）：换成论文文本配置后，STFT 的优势还能保持吗？

  - **实验目的：** 判断此前 STFT 的小幅提升是否只发生在某一种训练配置下。
  - **实验思路：** Global FLaG 和 E12 都采用 dropout 0.1、启用后池化 LayerNorm，重新运行十个种子。
  - **实验结果：** FLaG 的 Test Spearman 为 0.839065，E12 为 0.838944，两者基本持平。
  - **实验结论：** 在两种模型都使用 dropout=0.1、post-pool LayerNorm 的配置下，FLaG 与 E12 的 Spearman 基本相同，**实验配置也会影响，但是后续拿到原FLaG代码后全部对其了，不会影响**。

  ### 实验十五：通过数学推导解释 Padding 为什么会改变结果

  - **实验目的：** 找到即使 Gate 不变，仅仅改变 FFT 长度也会影响模型输出的原因。
  - **实验思路：** 根据 FLaG 对频谱实部和虚部分别乘不同 Gate 系数的操作，推导它对应的时域变换，并用数值计算验证。
  - **实验结果：** 发现输出不仅包含原位置的 token 特征，还包含循环反转位置的特征。当 FFT 长度改变时，反转位置也会改变。
  - **实验结论：** 实部和虚部采用不同 Gate 系数时，逆 FFT 会引入循环反射项；改变 FFT 长度会改变反射对应的位置，从而改变输出。

  ### 实验十六（P1）：Padding 的影响到底来自 Gate，还是频谱重建？

  - **实验目的：** 分清 Padding 导致预测变化的真正来源。
  - **实验思路：** 分别控制“生成 Gate 时采用的 FFT 长度”和“应用 Gate、逆 FFT 时采用的长度”，只改变其中一个。 补充实验中，再把实部与虚部 Gate 设为相同，去掉循环反射项。
  - **实验结果：** STSB validation 上，只改变 Gate 生成长度，平均 cosine 预测变化约 \(4.8\times10^{-7}\)；只改变逆变换长度，变化约 0.005520。 去掉循环反射后的输出与固定长度 128 的输出平均 cosine 差约为 0.000295。
  - **实验结论：** Padding 引起的预测差异主要来自应用 Gate 后的逆变换长度，而不是 Gate 的生成长度。取消循环反射后，也得到与固定重建长度相近的预测。

  ### 实验十七（P2）：Global 和 Local 的差异来自 Gate，还是重建方式？

  - **实验目的：** 找出全局 FFT 与局部 STFT 产生不同句向量的主要原因。
  - **实验思路：** 在相同 checkpoint 下，交叉使用 Global/Local 的 Gate 来源，以及 Global/Local 的频谱处理和重建路径。
  - **实验结果：** 只换 Gate 来源时，预测变化约为 \(10^{-7}\)；更换重建路径后，平均 cosine 变化约为 0.0058 至 0.0060。
  - **实验结论：** 在相同 checkpoint 下，Global 与 Local 的 Gate 来源互换几乎不改变预测，真正产生明显差异的是频谱处理和重建路线。

  ### 实验十八（S1）：把 STFT-FLaG 用到 Sprint，效果怎样？

  - **实验目的：** 检查 STFT 在 STSB 以外的任务中是否仍然有效。
  - **实验思路：** 冻结 RoBERTa，在 Sprint 上分别训练直接 Mean、Global FLaG 和 E12，比较三个种子的测试集性能。
  - **实验结果：** Mean、FLaG、E12 的 Test AP 分别为 0.428907、0.721611、0.765655。
  - **实验结论：** 这组 Sprint 实验中，E12 所使用的整套配置得到最高 Test AP。

  ### 实验十九（S2）：STFT 在 Sprint 上的优势是否稳定？

  - **实验目的：** 将 S1 的 Sprint 对照扩展至十个种子，观察两套配置的差距是否仍存在。
  - **实验思路：** 保持 S1 的两套配置不变，将 FLaG 和 E12 的实验扩展至十个seed。
  - **实验结果：** FLaG 的平均 Test AP 为 0.713121，E12 为 0.761344。E12 在十个种子中全部领先，平均高 0.048222。
  - **实验结论：** E12 的原有配置在十个种子中均高于 FLaG 的原有配置。

  ### 实验二十（S3）：在 Sprint 上，Global 和 Local 的预测差异来自哪里？

  - **实验目的：** 检查 STSB 上 P2 的机制发现，在 Sprint 上是否仍然成立。
  - **实验思路：** 固定训练好的模型，分别交换 Gate 来源和频谱重建方式，观察预测变化。
  - **实验结果：** 只更换 Gate，预测几乎不变。更换频谱重建路径后，平均 cosine 变化约为 0.032 至 0.037。
  - **实验结论：** Sprint 与 STSB 的 P2 结果一致：更换 Gate 来源几乎无影响，切换完整的频谱重建路线才会明显改变预测。

  ### 实验二十一（S4）：统一训练配置后，STFT 还比 Global FFT 好吗？

  - **实验目的：** 排除 S1/S2 中 dropout 和 LayerNorm 不一致带来的影响。
  - **实验思路：** 将 FLaG 和 E12 都设置为 dropout=0、启用后池化 LayerNorm，重新进行十个种子比较。
  - **实验结果：** FLaG 的平均 Validation AP 为 0.795830，E12 为 0.789136，E12 只在四个种子中领先。
  - **实验结论：** 将 dropout 与 LayerNorm 统一后，E12 的平均 Validation AP 反而低于 FLaG，模型配置影响大。

  ### 实验二十二（S5）：Dropout 和 LayerNorm 到底对 FLaG 有多大影响？

  - **实验目的：** 进一步解释为什么同一个 FLaG，在不同训练配置下性能差异明显。
  - **实验思路：** 固定 Global FLaG，只改变 dropout 是否为 0.1，以及是否启用后池化 LayerNorm，测试四种组合。
  - **实验结果：** 在十seed Validation AP 上，dropout=0.1 且启用 LayerNorm 的组合最高，为 0.819156；dropout=0.1 且关闭 LayerNorm 时仅为 0.750936。
  - **实验结论：** Global FLaG 在 dropout=0.1、启用 LayerNorm 时取得本次四种配置中最高的 Validation AP。两项设置的作用需要结合考虑。

  ### 实验二十三：删除不同频带，看看模型最依赖哪一部分

  - **实验目的：** 判断训练好的模型究竟依赖低频信息，还是也依赖其他频率的信息。
  - **实验思路：** 冻结 RoBERTa 和训练好的 FLaG，在不同 Transformer 层删除一个频带，再观察预测性能下降多少。
  - **实验结果：** 最后一层删除 B0 后，STSB 的 Spearman 从 0.710311 降到 0.492913；Sprint 的 AP 从 0.757690 降到 0.493323。两者下降都明显大于删除其他单个频带。
  - **实验结论：** 最后一层删除 B0 使 STSB 和 Sprint 的性能下降最多，表明最低频带是两种任务的重要信息来源。

  ### 实验二十四：如果只保留一个频带，模型还能预测好吗？

  - **实验目的：** 仅通过删除某个频带，不能说明该频带自己是否足够完成任务。因此反过来测试只保留一个频带的效果。
  - **实验思路：** 逐次仅保留一个频带，删除其他频率，使用原有模型预测，不重新训练。
  - **实验结果：** 在最后一层只保留 B0 时，STSB 保留完整模型 96.4% 的 Spearman，Sprint 保留 91.4% 的 AP，明显高于保留其他单个频带。
  - **实验结论：** 只保留最后一层 B0 就能恢复大部分完整模型性能，说明该频带本身已包含大量可供模型使用的任务信息。

  ### 实验二十五：不同 Transformer 层中的低频信息会怎样变化？

  - **实验目的：** 观察 RoBERTa 从浅层到深层，最低频带单独用于预测的效果如何变化。
  - **实验思路：** 在 RoBERTa 不同层分别只保留 B0，观察它还能恢复多少原模型的性能。
  - **实验结果：** STSB 的 B0-only 性能保留比例在 L1 为 20.7%，到 L12 为 96.4%；Sprint 从 L1 的 1.8% 上升到 L11 的 100.4%，L12 为 91.4%。
  - **实验结论：** 越靠近 RoBERTa 的高层，仅保留 B0 通常越能恢复原模型性能，说明深层低频成分已足以支持更强的任务预测。

  ### 实验二十六：训练时只使用 DC，模型还能取得高性能吗？

  - **实验目的：** 前面研究的是训练完成后删除频率。现在进一步判断：如果从训练开始就只让模型看到 DC，是否还能学到有效预测？
  - **实验思路：** 从头分别训练 Full FLaG、No-DC FLaG（去掉 DC）和 DC-only FLaG（仅保留 DC）。三种模型使用相同结构，只改变训练期间可见的频率。
  - **实验结果：** Seed 0 的 Sprint Test AP 分别为 0.724596、0.534044、0.894565。STSB Test Spearman 分别为 0.710535、0.646152、0.746003。
  - **实验结论：** 从训练开始只使用 exact DC，STSB 和 Sprint 的 seed-0 结果都高于 Full FLaG。这说明 DC 中的任务信息可以经可训练模型有效读取，而直接 Mean + cosine 未能充分利用它。

  ### 实验二十七：直接将 Mean 与 FLaG 的句向量加权融合

  - **实验目的：** 让模型可以在 Mean 与 FLaG 之间选择，而不是始终只能使用 FLaG。
  - **实验思路：** 同时计算 Mean 和 FLaG 表示，再学习一个权重 \(\alpha\)，决定两者在最终结果中的比例。
  - **实验结果：** Seed 0 中 STSB Spearman 为 0.850597，Sprint AP 为 0.878625。学到的 \(\alpha\) 在两个任务中均接近 0.5。
  - **实验结论：** 直接融合 Mean 和 FLaG 改善了本次 STSB、Sprint 结果，说明保留 Mean 路径有帮助。

  ### 实验二十八：只让 FLaG 补充 Mean 没有的信息，是否更好？

  - **实验目的：** 尝试避免重复使用 Mean 已经包含的内容，只补充 FLaG 与 Mean 不同方向上的信息。
  - **实验思路：** 将 FLaG 向量拆成沿 Mean 方向的部分，以及与 Mean 垂直的部分。以 Mean 为基础，只加入后者，并限制其权重 \(\beta\)。
  - **实验结果：** Seed 0 中 STSB Spearman 为 0.855106，但 Sprint AP 只有 0.638445，且 \(\beta\) 达到上界 1。
  - **实验结论：** 只使用 FLaG 相对 Mean 的正交部分使 STSB 提高、Sprint 明显下降，表明这种删去共线分量的方式不适合 Sprint。

  ### 实验二十九：放开补充信息的权重限制，会怎样？

  - **实验目的：** 判断 Sprint 表现差是否只是因为 \(\beta\) 的取值上限过小。
  - **实验思路：** 保持之前的向量分解方式不变，让 \(\beta\) 可以超过 1。
  - **实验结果：** Sprint AP 提高到 0.809582，但 \(\beta\) 增大到约 13.124。
  - **实验结论：** 允许 β 超过 1 后 Sprint AP 回升，但 β 增至约 13，说明模型需要大幅放大被保留的正交部分。

  ### 实验三十：为什么只保留与 Mean 垂直的部分，会损失信息？

  - **实验目的：** 解释为什么 Sprint 需要很大的 \(\beta\)，而 STSB 不需要。
  - **实验思路：** 计算 Mean 与 FLaG 句向量的夹角，并测量 FLaG 与 Mean 正交的部分有多大。
  - **实验结果：** 在当时的实验中，STSB 的 Mean 与 FLaG 夹角约 90.7°，Sprint 约 160.3°。也就是说，Sprint 中两者近乎反向。
  - **实验结论：** Sprint 的 FLaG 与 Mean 接近反方向，大部分 FLaG 表示位于 Mean 轴上。直接删除共线部分会丢掉模型原本能够利用的表示。

  ### 实验三十一：根据 Mean 与 FLaG 的方向关系进行融合

  - **实验目的：** 同时保留 Mean 的优势和 FLaG 的补充信息，避免上一种方法删除重要的共线部分。
  - **实验思路：** 设计 Alignment-aware 方法，根据两个向量的 cosine alignment 调整 Mean 的权重，再添加 FLaG 与 Mean 正交的部分。
  - **实验结果：** 早期 seed 0 的 STSB Spearman 为 0.858201，Sprint AP 为 0.880862。进一步按照原文本实验配置完成五种子对照，Alignment-aware 在 IMDB、STSB、Sprint 上的平均结果分别为 Accuracy 0.9526、Spearman 0.8536、AP 0.6989。
  - **实验结论：** Alignment-aware 在五种子对照中提高了 STSB 的 Spearman 和 Sprint 的 AP，IMDB 与 Mean 基本持平。按两种表示的方向关系融合，比只保留正交部分更有效。

  ### 实验三十二：FLaG 在哪一步改变了 Mean 向量？

  - **实验目的：** 找出 FLaG 为什么不能自动保持 Mean 的表示，以及具体是哪一部分改变了句向量方向。
  - **实验思路：** 将 FLaG 拆成 FFT、Gate、逆变换、Mean pooling 和 Projection 几个阶段。继承FLaG-A1 FLaG-zero想法，额外设计 B2，让模型初始时严格等于直接 Mean，再观察训练后的变化。
  - **实验结果：** B2 在第一个 epoch 后，Gate 使 STSB 和 Sprint 的 DC 平均转角分别达到约 64.7° 和 77.9°。最后的 Projection 还会进一步改变方向。
  - **实验结论：** FLaG 的 DC 与直接 Mean 原本同方向；。本次逐阶段测量表明，主要是 Gate 缩放和最终 Projection 改变了向量方向。

  ### 实验三十三：Gate 是否真的会根据不同句子产生不同权重？

  - **实验目的：** FLaG 通过 FFT 和 latent attention 为每句话生成 Gate，想知道这种针对不同输入的调整是否真的明显存在。
  - **实验思路：** 固定训练好的模型，把当前句子的 Gate 替换成训练集平均 Gate，或者其他句子的 Gate。随后进一步测量 Sigmoid 前后数值在不同句子之间的变化。
  - **实验结果：** 更换 Gate 后，STSB 和 Sprint 的指标在六位小数精度下保持不变。高精度检查发现，Sprint FLaG 的 Sigmoid 前输出仍存在明显变化，平均跨句子标准差为 0.439389，但最终 Gate 与训练集平均 Gate 的平均绝对差仅约 \(7.58\times10^{-14}\)。
  - **实验结论：** Gate 网络对不同句子的 Sigmoid 前输出有明显变化，但最终 Gate 几乎一致。高度饱和的 Sigmoid 大幅压缩了输入带来的差异。

  ### 实验三十四：Gate 主要在调整哪些特征通道？

  - **实验目的：** 解释为什么只有少量通道的 Gate 较低，却能够明显改变 DC 向量的方向。
  - **实验思路：** 找出 Gate 数值较低的实部通道，再计算这些位置在原始 DC 中占据多少平方能量。
  - **实验结果：** Sprint 中，原始 FLaG 约 2.21% 的低 Gate 值实部通道，承载了原始 DC 约 93.72% 的平方能量。B2 中相应比例为 3.78% 和 95.49%。
  - **实验结论：** 少量低 Gate 值通道承载了大部分原始 DC 平方能量，Gate 通过改变这些通道的相对权重影响向量方向。

  ### 实验三十五：训练好的 FLaG 究竟依赖 Gate 的哪一部分？

  - **实验目的：** 判断频谱中 DC、其他频率的 Gate，以及最终 Projection，分别会怎样影响预测。
  - **实验思路：** 固定训练好的模型，在推理时依次关闭 DC Gate、非 DC Gate、全部 Gate，以及绕过 Projection，比较性能变化。
  - **实验结果：** Sprint B2 的 Test AP 为 0.833946；关闭 DC Gate 后下降至 0.678850；绕过 Projection 后下降至 0.494782。而只关闭非 DC Gate，AP 基本不变。
  - **实验结论：** 当前已训练 B2 的 Sprint 预测对 DC Gate 和输出 Projection 较敏感，而关闭非 DC Gate 基本不改变 AP。

  ### 实验三十六：如果去掉 FFT 和 Attention，简单模型能否达到相近性能？

  - **实验目的：** 判断完整的频域门控是否真的必要，还是只要在 Mean 向量之后加入一个可训练的线性层就够了。
  - **实验思路：** 从零训练三个简化模型：固定实部/虚部通道权重、固定逐通道权重，以及直接 Mean + 可训练 Projection，并与完整 B2 比较。
  - **实验结果：** Seed 0 的 Sprint Test AP 中，B2 为 0.834217，直接 Mean + Projection 为 0.833765，仅差 0.000452。
  - **实验结论：** 在本次 Sprint 的 seed-0 对照中，Mean + 可训练 Projection 几乎恢复了 B2 的 AP，说明复杂的 FFT/Attention/Gate 不是达到这一结果所必需的训练结构。

  ### 实验三十七：Projection 的初始化方式会影响结果吗？

  - **实验目的：** 进一步理解为什么简单的 Mean + Projection 表现不差，并排除不同初始化方式造成的比较偏差。
  - **实验思路：** 对比随机初始化和单位矩阵初始化的 Mean + Projection，并与 FLaG、B2 一起进行三个seed的训练。统一使用验证集 AP 选择模型。
  - **实验结果：** 随机初始化 Mean + Projection 的平均 Sprint Test AP 为 0.840923，单位矩阵初始化为 0.818806。前者在三个seed中都更高。
  - **实验结论：** 随机初始化的 Mean + Projection 比单位矩阵初始化高 0.022117 AP，表明输出线性层的初始化会显著影响本次训练结果。

  ### 实验三十八：在相同初始 Projection 下，完整 FLaG 还有额外优势吗？

  - **实验目的：** 令 FLaG 与 Mean + Projection 使用完全相同的初始线性层，直接比较加入完整频域门控前后的 Sprint 预测性能。
  - **实验思路：** 强制两个模型使用完全相同的初始 Projection 权重与偏置，保持相同的数据划分和训练协议，运行三个种子。
  - **实验结果：** Sprint Test AP 中，FLaG 为 0.830539 ± 0.016711，Mean + Projection 为 0.841386 ± 0.008833。三个种子中简单模型全部领先。不过 Validation AP 的平均值是 FLaG 略高。
  - **实验结论：** 在严格统一初始 Projection 后，Mean + 可训练线性层的 Sprint Test AP 为 0.841386，高于完整 FLaG 的 0.830539，三个seed结果方向一致:完整频域门控没有在这次对照中带来额外测试集收益。
