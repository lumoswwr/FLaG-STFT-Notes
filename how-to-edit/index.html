    Markdown 使用说明¶

    这份项目以后只需要维护 docs/ 里面的 .md 文件，不需要手写 HTML。

    1. 标题¶

    # 一级标题
## 二级标题
### 三级标题

    在实验页面中，通常一个实验使用二级标题：

    ## S6

    5. 图片¶

    把图片放进：

    docs/assets/images/

    然后在 Markdown 中写：

    ![图片说明](../assets/images/example.png)

    如果当前 Markdown 文件在 docs/ 根目录，则路径写成：

    ![图片说明](assets/images/example.png)

    6. 数学公式¶

    行内公式：

    当 $a=b$ 时，反射项消失。

    独立公式：

    $$
y[t] = \alpha x[t] + \beta x[(-t) \bmod N]
$$

    7. 新增一个实验¶

    例如以后新增 S6，只需要打开：

    docs/sprint/02-experiments.md

    在文件末尾追加：

    ## S6

**Q:**

这里写问题。

**M:**

这里写方法。

**R:**

这里写结果。

**C:**

这里写结论。

    保存后，mkdocs serve 启动的网页会自动刷新。

    8. 最常用的三个命令¶

    mkdocs serve

    本地实时预览。

    mkdocs build

    生成最终 HTML 网站到 site/。

    Ctrl + C

    在终端中停止 mkdocs serve。
