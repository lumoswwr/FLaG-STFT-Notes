    STSB：Padding、窗口重叠和配置复核¶

    先看实验概览：下面逐项说明实验目的、做法、结果和结论。需要复查具体配置、原始指标及计算方法时，再阅读后面的详细实验记录。不同实验的 test、validation 与随机种子信息以详细记录为准。

    本页实验概览（6 项）¶

    对应文件： docs/stsb/02-padding.md

    接着检查两个实际问题：增加无效 Padding 为什么影响预测？之前局部 STFT 的小幅提升是否来自窗口重叠、FFT 长度或训练配置？

    实验九（E9）：只增加 Padding，为什么预测会变化？¶

    • 实验目的： 检查模型是否会受到无效 padding 位置的影响。
    • 实验思路： 固定 RoBERTa 已计算好的有效 token 特征，只在后面增加零 padding，分别比较 Global FLaG 和 E3 的预测结果。
    • 实验结果： 当补零长度达到 128 时，Global FLaG 的平均 cosine 预测变化约为 0.006003，最大为 0.035915；E3 几乎没有变化。
    • 实验结论： 仅在有效 token 后增加零 Padding，就会改变 Global FLaG 的输出；E3 对这项操作基本不敏感。

    实验十（E10）：Padding 的变化会影响整个测试集的预测性能吗？¶

    • 实验目的： 验证 E9 中观察到的预测变化，是否进一步影响 STSB 的整体 Spearman。
    • 实验思路： 使用动态 padding、句对统一长度、每句精确长度以及统一长度 128 四种方式进行推理，不重新训练模型。
    • 实验结果： FLaG 的平均 Test Spearman 在 0.841022 至 0.841458 之间变化，E3 基本保持 0.843000。
    • 实验结论： Global FLaG 的 Spearman 随 Padding 策略发生小幅变化，E3 基本不变；Padding 敏感性不能单独解释两者的全部性能差异。

    实验十一（E11/E12）：STFT 的窗口必须重叠吗？¶

    • 实验目的： 判断相邻窗口的重叠是否真的能够提高模型性能。
    • 实验思路： 比较窗口长度为 8 和 16，以及半窗口重叠和完全不重叠的四种组合。
    • 实验结果： 长度 8 时，重叠版本 E3 略好；长度 16 时，不重叠版本 E12 更好。E12 的三种子 Test Spearman 为 0.843419。
    • 实验结论： 窗口重叠并非获得较好 STSB 结果的必要条件；在长度 16 的设置中，无重叠 E12 更好，因此后续采用 E12。

    实验十二（E12 扩展）：E12 的提升在十个随机种子下稳定吗？¶

    • 实验目的： 在三种子比较中 E12 较好，进一步通过十个随机种子检查两种模型的实际性能差距。
    • 实验思路： 在相同 dropout 和 LayerNorm 配置下，将 Global FLaG 与 E12 都扩展到十个随机种子。
    • 实验结果： E12 平均 Test Spearman 为 0.842739，FLaG 为 0.841559。E12 平均高 0.001180，十个种子中七次领先。
    • 实验结论： E12 的平均 Spearman 比全局 FLaG 高 0.001180，但两者整体非常接近；这轮验证没有形成明显的性能差距。

    实验十三（E13）：固定 Global FFT 长度能否改善模型？¶

    • 实验目的： 既然 Global FLaG 对 padding 长度敏感，想知道从训练开始固定 FFT 长度是否能改善性能。
    • 实验思路： 训练和推理时都将 FFT 长度固定为 128，其他模型结构保持不变。
    • 实验结果： Test Spearman 为 0.841856，相比动态 FFT 的平均配对差为 +0.000728，但只有一个种子领先。
    • 实验结论： 将 FFT 长度固定为 128 后，Spearman 与动态长度版本接近，没有带来实际的性能改善。

    实验十四（E14）：换成论文文本配置后，STFT 的优势还能保持吗？¶

    • 实验目的： 判断此前 STFT 的小幅提升是否只发生在某一种训练配置下。
    • 实验思路： Global FLaG 和 E12 都采用 dropout 0.1、启用后池化 LayerNorm，重新运行十个种子。
    • 实验结果： FLaG 的 Test Spearman 为 0.839065，E12 为 0.838944，两者基本持平。
    • 实验结论： 在两种模型都使用 dropout=0.1、post-pool LayerNorm 的配置下，FLaG 与 E12 的 Spearman 基本相同；此前 E12 的小幅领先没有继续出现。

    本篇小结： Global FLaG 会因 Padding 长度改变而产生预测漂移；在匹配的配置下 E12 与 Global FLaG 表现非常接近，局部 STFT 没有形成明显的性能优势。

    详细实验记录与数据¶

    E9/E10 使用已训练的 FLaG 与 E3 做 padding 测试；E11/E12/E13/E14 是重新训练的配置对照。STSB 基础训练参数见实验设置。

    实验配置对照¶

    实验 改变什么 Seeds 指标

    E10 normal / pair_exact / sentence_exact / fixed_128 0–2（3 个） test Spearman
    E11 STFT win8/hop8，无重叠 0–2（3 个） test Spearman/Pearson
    E12 STFT win16/hop16，无重叠 先 0–2，后扩至 0–9 test Spearman/Pearson

    E9：额外右 Padding 的影响¶

    Q： 同一句子只增加右侧零 padding，FLaG 与 E3 的预测是否变化？

    M： 固定 FLaG/E3 checkpoint，选择有效长度 ≤16 的 STSB 短句。保持 RoBERTa 产生的有效 hidden 不变，分别补零到 16、24、32、64、128，再传入 pooling；计算相对精确有效长度处理的句对 cosine 绝对差。

    R： 补零至 128 时：

    指标 FLaG E3
    平均绝对 cosine 漂移 0.006003 约 0
    最大绝对 cosine 漂移 0.035915 约 0

    C： 当前 global FLaG 对外部右 padding 敏感；E3 在这项固定 hidden 测试中近似不变。

    记录待核对：现有摘要没有给出这张结果表所对应的完整运行命令。探针脚本默认 seed=0、最多 200 对样本，但正式确定实验数量需要检查原始日志。

    E10：四种 Padding 推理方式¶

    Q： E9 的预测变化是否明显影响整个 STSB test 的性能？

    M： 使用 FLaG/E3 的 3-seed checkpoint，每句话只计算一次 RoBERTa hidden，之后采用四种 pooling 输入长度，不重新训练：

    设置 处理方式
    normal 原始 batch 动态 padding
    pair_exact 同一对两句都补到二者较大的有效长度
    sentence_exact 每句分别使用自身有效长度
    fixed_128 每句统一补零到 128

    R： 3-seed mean test Spearman：

    Padding FLaG E3
    normal 0.841128 0.843000
    pair_exact 0.841022 0.843000
    sentence_exact 0.841288 0.843000
    fixed_128 0.841458 0.843000

    C： Padding 会改变 FLaG 的预测和少量 test Spearman，但未能解释全部 FLaG/E3 性能差异。

    E11/E12：窗口大小与重叠¶

    Q： STFT 是否一定需要窗口重叠？

    M： 比较 win8/win16 与半窗重叠/无重叠，共四种 rect、center=False 的 STFT 配置。沿用 E2/E3，并补充重新训练 E11/E12，每组 3 seeds（0–2），其他参数一致。

    R： 3-seed test Spearman（mean ± std）：

    窗长 半窗口重叠 无重叠
    8 E3：hop4，0.843000 ± 0.001047 E11：hop8，0.842166 ± 0.001423
    16 E2：hop8，0.842204 ± 0.001824 E12：hop16，0.843419 ± 0.000531

    C： 重叠没有一致优势。后续固定使用结构简单的 E12：rect、win16/hop16、center=False。

    E12 的 10-seed 稳定性¶

    将原匹配设置（FLaG/E12 都为 dropout=0、Norm=True）扩至 10 seeds（0–9）：

    模型 test Spearman ↑ test Pearson ↑
    FLaG 0.841559 ± 0.003538 0.838504 ± 0.003444
    E12 0.842739 ± 0.003214 0.839393 ± 0.003467
    配对 E12−FLaG +0.001180 ± 0.002107 +0.000889 ± 0.003033

    Spearman 7/10 seeds 正向，配对 95% CI 约 [−0.00033, +0.00269]。虽然平均差为正，但不足以说明稳定优势。

    E13：从训练开始固定 FFT 长度¶

    Q： 如果 global FLaG 在训练时就使用固定 FFT 长度，能否改善结果？

    M： global FLaG 在训练及推理时均设 fixed_fft_length=128；不引入 STFT，其他设置不变，3 seeds（0–2）。

    R： test Spearman 0.841856 ± 0.001000；相对同 seed 动态 FLaG 的配对差为 +0.000728 ± 0.003079，仅 1/3 正向。

    C： 固定 FFT 长度没有带来稳定的性能改善。

    E14：统一论文 Text 配置¶

    Q： 在论文 text 配置下，E12 相比 FLaG 的早期性能趋势是否仍存在？

    M： FLaG 与 E12 都改为 dropout=0.1、post-pool Norm=True，其余训练设置匹配，重新训练 10 seeds（0–9）。

    R： 10-seed test：

    模型 Spearman ↑ Pearson ↑
    FLaG 0.839065 ± 0.004154 0.834980 ± 0.003942
    E12 0.838944 ± 0.001882 0.834015 ± 0.002119
    配对 E12−FLaG −0.000121 ± 0.004039 −0.000965 ± 0.003878

    Spearman 5/10 seeds 正向。

    C： 两者基本持平。E12 在 0/有 Norm 下的小幅正向均值没有在这组 0.1/有 Norm 实验中保持。
